## The problem we're solving

An application assumes Next.js middleware provides authentication by adding a UI redirect, without enforcing permission at its API and data layer. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

In Next.js 16, Middleware is renamed Proxy. A proxy can implement early routing and response headers but is not the only authorization boundary; every private data handler must verify the caller. Apply security headers coherently and test them on actual responses.

**Predict before running:** The repaired implementation respects its documented contract.
