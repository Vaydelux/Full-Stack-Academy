## The problem we're solving

The starter ignores the audit flags and always reports a clean interface. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Review a real flow against clear categories—keyboard, contrast, error feedback, layout stability and mobile reachability—and return actionable high-priority findings.

**Expected outcome:** A failed keyboard, contrast or error criterion becomes an explicit finding; all passing criteria produce no findings.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
