## The problem we're solving

A UI review rubric gives a passing grade even when critical focus failures and unlabelled controls remain unresolved.

## Build the mental model

A professional UX release review records observations, severity, affected user journeys and evidence, then blocks release on critical accessibility failures. Distinguish subjective visual preference from objective keyboard failures, missing labels and data loss.

**Predict first:** An unresolved critical issue blocks release; only resolved or absent issues permit passing status.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-annotated-ux-review/starter/solution.ts" expected="An unresolved critical issue blocks release; only resolved or absent issues permit passing status.">

```ts

export type Issue={severity:"low"|"medium"|"critical";resolved:boolean};export function solve(issues:readonly Issue[]):string{const active=issues.filter(x=>!x.resolved);return active.some(x=>x.severity==="critical")?"blocked":active.length?"review":"pass";}

```

**Why it works:** A professional UX release review records observations, severity, affected user journeys and evidence, then blocks release on critical accessibility failures. Distinguish subjective visual preference from objective keyboard failures, missing labels and data loss.

**Proof:** Run `npm run lab:ui-annotated-ux-review` and inspect the instructor test output.

</LessonStep>
