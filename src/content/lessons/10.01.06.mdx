## The problem we're solving

A telemetry dashboard reports zeros for RSS, heap and CPU because the metrics are mocked rather than sampled from the actual Node process.

**Deliberate defect:** The starter returns fixed zeros and misleadingly labels them as real measurements. This exercise runs under Node.js 24 using built-in modules—no paid service, hosted data source or arbitrary learner-code runner.

## Build the mental model

Measure process.memoryUsage and process.cpuUsage and distinguish RSS from V8 heap-used before optimizing CPU-bound work.

**Predict before writing code:** RSS/heap/CPU readings are nonnegative process metrics, not fabricated counters.

The exact Node.js API documentation is linked below. These exercises model concrete runtime behavior, not a screenshot of a server. They must not be interpreted as proof of container permission boundaries, a production reverse proxy or multi-process request isolation.
