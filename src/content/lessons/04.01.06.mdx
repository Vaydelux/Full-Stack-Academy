## The problem we're solving

An unknown API object is asserted to contain a string name, causing errors when the value is null or nested data differs. The checked-in examples are TypeScript 5 modules targeting the repository's strict compiler settings. Node 24 plus the installed tsx runner execute the instructor tests without a remote environment.

## Build the mental model

Narrowing refines a union after a runtime condition; user-defined type predicates can communicate those checks to the compiler. Asserting unknown as a shape without checking the discriminating fields risks errors and false confidence.

**Predict before running:** Only a runtime-verified string name is transformed; all other unknown values return a safe result.

<LessonStep number={2} title="Implement the typed repair" file="labs/ts-guards/starter/solution.ts" expected={"Only a runtime-verified string name is transformed; all other unknown values return a safe result."}>

Preserve exported `solve`; narrow unknown inputs and maintain the intended inferred/annotated return contract.

```ts
type Person={name:string};function isPerson(value:unknown):value is Person{return !!value&&typeof value==='object'&&'name' in value&&typeof value.name==='string';}export function solve(value:unknown):string{return isPerson(value)?value.name.toUpperCase():'UNKNOWN';}
```

**Predict before running:** Only a runtime-verified string name is transformed; all other unknown values return a safe result.

**Why it works:** Narrowing refines a union after a runtime condition; user-defined type predicates can communicate those checks to the compiler. Asserting unknown as a shape without checking the discriminating fields risks errors and false confidence.

**Proof:** Compare the repaired student's output with the instructor solution under the same typed test cases.

</LessonStep>

<LessonStep number={3} title="Exercise runtime and compiler contracts" file="labs/ts-guards/solution.test.mjs" expected="The reviewed solution has a passing strict TypeScript compile and actual regression assertions.">

```ts
assert.equal(solve({name:'Ada'}),'ADA');assert.equal(solve({name:3}),'UNKNOWN');assert.equal(solve(null),'UNKNOWN');
```

**Predict before running:** Correct runtime behavior and a valid static type signature are separate, both required.

**Why it matters:** TypeScript cannot block malformed JSON after the source has been compiled; user input still needs runtime guards.
