## The problem we're solving

A button looks interactive on hover but has no keyboard focus indicator. Our task is to repair the actual style behavior, not just make a static screenshot look convincing. This workshop uses synthetic content in a standalone offline HTML file; it needs no account, cloud API or deployed preview.

## Build the mental model

:hover follows pointer hover; :focus-visible is a UA-informed indicator for keyboard-like focus and is not necessarily shown for every mouse click. :disabled matches natively disabled controls; [aria-disabled] is only semantic unless behavior is implemented. Never remove the focus outline without a replacement.

**Predict before running:** Keyboard Tab gives the action a thick orange focus ring; hovering changes only its background.

<LessonStep number={2} title="Apply the targeted CSS repair" file="labs/css-states/starter/index.html" expected="Keyboard Tab gives the action a thick orange focus ring; hovering changes only its background.">

Replace the incorrect rule with the following CSS. Keep the native HTML controls and all semantic content unchanged.

```css
.action:focus-visible { outline: 3px solid #c44804; outline-offset: 4px; }
```

**Predict before running:** Keyboard Tab gives the action a thick orange focus ring; hovering changes only its background.

**Why it works:** :hover follows pointer hover; :focus-visible is a UA-informed indicator for keyboard-like focus and is not necessarily shown for every mouse click. :disabled matches natively disabled controls; [aria-disabled] is only semantic unless behavior is implemented. Never remove the focus outline without a replacement.

**Proof:** Use Tab and inspect :focus-visible plus outlineWidth on the action button.

</LessonStep>

**Why it works:** Browser-computed styles and measured dimensions describe actual rendered rules, rather than assuming the presence of source text is enough.

**Proof:** Compare the computed result with the instructor solution and record one failing case from the original starter.
