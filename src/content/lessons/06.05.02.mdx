## The problem we're solving

A test selects the third button by position and silently starts clicking a different action after layout changes. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Role- and accessible-name-based queries select controls how assistive technology does. Use getByRole with name for interactive elements; visible text and label associations are generally more stable than CSS order or generated IDs.

**Predict before running:** The repaired implementation respects its documented contract.
