## The problem we're solving

A multi-step checkout test checks only the initial state, missing that an empty cart can still be submitted. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

User journey tests should follow realistic interactions through meaningful state transitions. They verify validation, submission and visible feedback, not just snapshots. Include negative paths and keyboard behavior in a real browser or jsdom environment.

**Predict before running:** The repaired implementation respects its documented contract.
