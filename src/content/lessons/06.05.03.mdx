## The problem we're solving

A checkout flow should not complete without terms accepted and must allow a confirmed submission. **Failure case:** The starter permits submission before consent, so an end-to-end journey skips a required business rule.

## Build the mental model

Model a complete interaction as state transitions with preconditions, visible success and failure states.

**Expected result:** Unaccepted terms block checkout; acceptance enables a completed state with visible confirmation.

**Evidence boundary:** Node tests run reviewed fixtures, not arbitrary learner code. React server markup proves initial output only. A browser or configured DOM environment is required for real user events, hydration, the React DevTools Profiler, and state preservation after reordering. This repo does not currently declare or lock React Testing Library; do not claim these Node checks exercise that dependency.

<LessonStep number={2} title="Repair the implementation contract" file="labs/react-user-journey/starter/solution.tsx" expected="Unaccepted terms block checkout; acceptance enables a completed state with visible confirmation.">

```tsx
import {useReducer} from 'react';
export type Flow={accepted:boolean;stage:'editing'|'complete'};
export type FlowAction={type:'toggle'}|{type:'submit'};
export function flowReducer(state:Flow,action:FlowAction):Flow{
 if(action.type==='toggle')return {...state,accepted:!state.accepted};
 if(action.type==='submit'&&state.accepted)return {...state,stage:'complete'};
 return state;
}
export function CheckoutFlow(){
 const [state,dispatch]=useReducer(flowReducer,{accepted:false,stage:'editing'});
 return <section><label><input type="checkbox" checked={state.accepted} onChange={()=>dispatch({type:'toggle'})}/>Accept terms</label>
 <button type="button" disabled={!state.accepted||state.stage==='complete'} onClick={()=>dispatch({type:'submit'})}>Submit order</button>
 <p role="status">{state.stage==='complete'?'Order confirmed':'Order pending'}</p></section>;
}
```

**Why this works:** Model a complete interaction as state transitions with preconditions, visible success and failure states.

</LessonStep>
