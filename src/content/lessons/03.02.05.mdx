## The problem we're solving

A module imports a legacy sanitizer that trims text but forgets to lowercase normalized tags. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

ES modules use static import/export bindings. Named exports create explicit contracts; relative paths resolve to separate modules and are cached by module URL. A public export should deliberately depend on the reviewed helper, not a similarly named legacy function.

**Predict before running:** The public solve export uses the normalized helper, which rejects blanks and produces canonical tags.
