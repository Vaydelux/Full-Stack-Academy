## The problem we're solving

The starter returns a perfect ratio for every pair. A robust component system has to work across dark and light themes, keyboard input, small screens and real data, not merely appear correct in a screenshot.

## Build the mental model

Calculate WCAG relative-luminance contrast for theme foreground/background pairs; verify both themes and component states. **Predict before executing:** Black and white have 21:1 contrast and identical colors 1:1.

**Runtime boundary:** This lesson's fixture is local TypeScript only. It does not compile Tailwind CSS, install shadcn or Radix/Base UI, mount a browser interaction, or verify visual contrast on real content. Those require a dedicated UI build and accessibility checks.

```tsx
function lum(h:string){if(!/^#[\da-f]{6}$/i.test(h))throw new Error('Invalid hex');const rgb=[1,3,5].map(i=>parseInt(h.slice(i,i+2),16)/255).map(v=>v<=.04045?v/12.92:((v+.055)/1.055)**2.4);return .2126*rgb[0]+.7152*rgb[1]+.0722*rgb[2];}export function ratio(a:string,b:string){const x=lum(a),y=lum(b);return (Math.max(x,y)+.05)/(Math.min(x,y)+.05);}
```
