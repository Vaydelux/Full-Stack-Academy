## The problem we're solving

A tutorial says run export PORT=3000, but PowerShell reports that export is not recognized. The command is for a different shell. The terminal displays a shell; the shell interprets input; the operating system provides paths, processes and permissions.

## Build the mental model

PowerShell operates on objects and uses commands such as Get-Location and Get-ChildItem; Bash typically passes text through pipelines and uses pwd and ls. Windows paths have drive letters; POSIX paths use a root slash. WSL2 runs a Linux environment with its own PATH, installed Node, Git, permissions and filesystem. Prefer the Linux home filesystem for projects developed inside WSL; avoid reusing node_modules across Windows and Linux. Quoting differs: use argument arrays in programmatic process launches rather than concatenating shell strings. Relative paths resolve from the current working directory, not necessarily the script directory.

<LessonStep number={3} title={"Implement a portable path helper"} file="labs/terminal-workflow/starter/exercise.mjs" expected={"A relative file resolves inside the supplied workspace and a parent escape is rejected."}>

Use path.resolve and path.relative. For this lesson we enforce lexical containment only; symlinks can still escape a directory, so this is not a production authorization boundary.

```js
import path from 'node:path';
export function within(root, name) {
  if (path.isAbsolute(name)) throw new Error('Relative path required');
  const base = path.resolve(root);
  const target = path.resolve(base, name);
  const relative = path.relative(base, target);
  if (relative === '..' || relative.startsWith('..'+path.sep) || path.isAbsolute(relative)) throw new Error('Outside workspace');
  return target;
}
```

</LessonStep>

## Bug Hunt: diagnose before you change code

A script assumes the current directory equals its own directory. Running it from a parent produces missing-file errors. Print process.cwd(), inspect the shell location, and pass an explicit root or use a path derived from import.meta.url.
