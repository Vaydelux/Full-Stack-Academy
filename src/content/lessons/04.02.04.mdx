## The problem we're solving

A typed wrapper declares the correct resolved type but returns an invented undefined value rather than unwrapping a Promise. This advanced-types lab requires both compile-time evidence and meaningful runtime behavior; TypeScript's erased types alone cannot fix logic bugs.

## Build the mental model

Conditional types choose one type branch based on assignability. The infer keyword can extract part of a related type, such as a Promise's resolved value. This extraction happens only during type checking; runtime Promise resolution still requires actual code.

**Predict before running:** A Promise resolves to the expected value while the type-level Unwrap preserves its result type.
