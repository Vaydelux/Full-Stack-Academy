## The problem we're solving

An async form reports success even when the submitted name is blank, and its pending state is never exposed. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

useActionState coordinates a form Action's returned state and pending indicator. The Action receives previous state before form payload. Validate input at the boundary and return an explicit status; a server action still needs authorization and CSRF-safe design.

**Predict before running:** The repaired implementation respects its documented contract.
