## The problem we're solving

A feedback form must report short or empty messages and announce the result after a submission. The starter accepts every input, including an empty message, and always reports success.

## Build the mental model

Return typed validation feedback from a React form Action without storing duplicated submission flags. A state value, an Action dispatcher and a pending flag that reflect the Action's lifecycle. The React 19 APIs used here have distinct contracts: context passes values, transitions schedule nonurgent updates, deferred values let rendering lag, and optimistic state is a temporary view during an Action. These lessons use local data, not backend persistence.

**Predict before you run:** Blank and very short messages are rejected; valid submissions return a typed success state.

<LessonStep number={2} title="Repair the React 19 component contract" file="labs/react-use-action-state/starter/solution.tsx" expected="Blank and very short messages are rejected; valid submissions return a typed success state.">

The instructor repair preserves the public exports while fixing the value propagation, scheduling, or state reconciliation defect:

```tsx
import {useActionState} from 'react';
export type FeedbackResult={ok:boolean;message:string};
export async function checkFeedback(_previous:FeedbackResult,data:FormData):Promise<FeedbackResult>{
 const text=data.get('feedback');
 if(typeof text!=='string'||text.trim().length<3)return {ok:false,message:'Enter at least 3 characters'};
 return {ok:true,message:'Accepted local feedback'};
}
export function FeedbackForm(){
 const [result,action,pending]=useActionState(checkFeedback,{ok:false,message:'No submission yet'});
 return <form action={action}><label htmlFor="feedback-input">Feedback</label>
 <textarea id="feedback-input" name="feedback"/><button type="submit" disabled={pending}>Send</button>
 <p role="status">{result.message}</p></form>;
}
```

**Why it works:** Return typed validation feedback from a React form Action without storing duplicated submission flags.

</LessonStep>
