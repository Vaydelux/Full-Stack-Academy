## The problem we're solving

The starter reports Empty whenever rows are zero, even during an error or loading operation. Enterprise interfaces need correct data scope, stable identities, accessible states and predictable behavior under pagination, refresh and mobile layouts.

## Build the mental model

Differentiate pending, empty, failed and ready states; communicate errors without rendering a misleading empty dataset.

**Prediction:** Error and loading take priority over emptiness; ready appears when data exists.

**Scope of evidence:** The instructor's local Node tests exercise a pure data transformation. TanStack Table v8 and TanStack Virtual require separate dependency installation and mounted browser tests. Never treat sorting the current server page as global sorting, or browser-side role checks as server authorization.
