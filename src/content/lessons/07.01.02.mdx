## The problem we're solving

A navigation shell is repeated in every page instead of being shared by the segment layout, causing unnecessary remounting. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A layout wraps child routes and usually preserves state across navigation, while a template creates a new instance on relevant navigation. Pages expose route content. Use layouts for persistent navigation and templates only when remount behavior is required.

**Predict before running:** The repaired implementation respects its documented contract.
