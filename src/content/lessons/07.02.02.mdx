## The problem we're solving

A render pipeline assumes client hydration must complete before any HTML can be sent to the browser. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

The server renders React Server Components into a transport payload and HTML can stream with Suspense boundaries; client components later hydrate interactive portions. Distinguish server render, streamed HTML, client hydration and subsequent navigation rather than collapsing them into one synchronous step.

**Predict before running:** The repaired implementation respects its documented contract.
