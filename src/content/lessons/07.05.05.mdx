## The problem we're solving

Error tracking matters in a production-facing Next.js application. **Initial defect:** The starter serializes all error context fields into the log, including credentials.

## Build the mental model

Emit bounded diagnostic identifiers and error codes without logging access tokens, raw email addresses or other personal data. **Predict:** Only requestId, operation and errorCode remain after redaction.

These source tests are not a replacement for real Next.js build, authentic requests, tenant-scoped database reads, observability or production deployment checks.
