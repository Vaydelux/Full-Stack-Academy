## The problem we're solving

A public error reporter logs a full error object containing sensitive request headers and exposes the stack to the client. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Capture errors with a sanitized public code and a server-side correlation ID. Keep detailed diagnostics in access-controlled logs with retention controls; do not serialize authorization headers, cookies, tokens or full stack traces to browser responses.

**Predict before running:** The repaired implementation respects its documented contract.
