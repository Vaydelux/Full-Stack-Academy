## The problem we're solving

A tutorial looks polished but every section title is a bold paragraph; users who navigate by headings cannot find any of its sections.

## Build the mental model

Heading elements `h1` through `h6` identify hierarchical sections. `h1` usually names the page; `h2` identifies major sections and `h3` names subsections. Choosing levels by font size breaks the document outline; use CSS for appearance. Skipped levels are not universally forbidden by the HTML parser, but can make the hierarchy harder to follow. The HTML outline algorithm is not a substitute for thoughtful headings. A unique page-level heading is a reliable default for basic documents.

**Predict before running:** If a small caption looks like a heading but isn't a section title, should it be an h4 only because its font is small? No.

## Prerequisites

Complete [the previous lesson](/learn/01.01.03) or review its objectives. A browser, text editor, Node.js 24 and this repository are enough. These examples are intentionally standalone and avoid remote services, account credentials or arbitrary browser scripts.

<LessonStep number={1} title={"Create one descriptive page title"} file="labs/html-headings/starter/index.html" expected={"The heading list starts with one clear page-level title."}>

Make the top-level title an h1 rather than a styled div. Make it specific to the document.

```html
<main>
  <h1>Plan a community workshop</h1>
</main>
```

</LessonStep>

<LessonStep number={2} title={"Group major topics with h2"} file="labs/html-headings/starter/index.html" expected={"The hierarchy contains an h1 followed by meaningful h2 sections."}>

Introduce two sections, each with an ID used in its parent section label.

```html
<section aria-labelledby="prepare">
  <h2 id="prepare">Prepare the room</h2>
  <p>Check the layout and equipment.</p>
</section>
<section aria-labelledby="session">
  <h2 id="session">Run the session</h2>
  <p>Welcome attendees and explain the plan.</p>
</section>
```

</LessonStep>

<LessonStep number={3} title={"Nest a focused subsection with h3"} file="labs/html-headings/starter/index.html" expected={"Heading navigation reveals the equipment check beneath the preparation topic."}>

Use h3 only when describing a subtopic within a major section, not merely because it looks smaller.

```html
<section aria-labelledby="equipment">
  <h3 id="equipment">Equipment check</h3>
  <p>Inspect cables and power safely.</p>
</section>
```

</LessonStep>

## Bug Hunt: diagnose before changing markup

A designer renders every headline as h1 for consistent font styling. The document loses its hierarchy. Keep one page h1, introduce h2 sections and use CSS classes for visual consistency.
