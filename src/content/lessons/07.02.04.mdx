## The problem we're solving

A Server Action accepts an unvalidated quantity and updates inventory without checking authorization or idempotency. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Server Functions are remotely invokable server endpoints regardless of which UI invokes them. Validate user input and authorization inside each mutation, consider CSRF defenses and rate limits, then invalidate affected cached views only after successful persistence.

**Predict before running:** The repaired implementation respects its documented contract.
