## The problem we're solving

A documentation panel should wrap either text or interactive content using one accessible shell. Hardcoding panel body content prevents reuse and drops content passed by callers. This lesson uses local React 19 / TypeScript 5 fixtures; the website does not execute learner-provided code.

## Build the mental model

Use children for reusable containment without coupling the panel to its contents. It is the React node tree placed between a component's opening and closing tags. A React element is a description of UI; server rendering verifies initial markup but cannot, by itself, prove a browser interaction, reconciliation, or a DOM commit.

**Predict before you run:** A named region contains the caller's child content without changing it.

import type { ReactNode } from 'react';
export function Panel({ title, children }: {title:string; children:ReactNode}) {
  return <section aria-label={title}><h2>{title}</h2><div>{children}</div></section>;
}
