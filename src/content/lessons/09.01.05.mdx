## The problem we're solving

A browser form submits age as a string and an email with inconsistent case; numeric conversion must not silently accept impossible ages.

**Broken behavior:** The starter expects a numeric age already and leaves the email uppercase.

## Build the mental model

Use constrained coercion at the input boundary and transforms for normalized output; explicitly distinguish z.input from z.output types.

**Predict before coding:** Parse age '21' to number 21, lowercase email, reject invalid or underage inputs.

**Important boundary:** TypeScript types are erased at runtime. These exercises import Zod 4 from the repository's locked dependencies and run actual `safeParse` or `parse` assertions, not simulated validation. Runtime validation does not authenticate a caller, authorize object access, or persist data.

<LessonStep number={2} title="Implement the Zod 4 schema and typed output" file="labs/zod-transform-coerce/starter/solution.ts" expected="Parse age '21' to number 21, lowercase email, reject invalid or underage inputs.">

```ts
import * as z from 'zod';
export const Contact=z.strictObject({
 email:z.email().transform(email=>email.toLowerCase()),
 age:z.coerce.number().int().min(18).max(120),
});
```

**Why this works:** Use constrained coercion at the input boundary and transforms for normalized output; explicitly distinguish z.input from z.output types.

</LessonStep>

**Representative application usage:**

```ts
import * as z from 'zod';
const Contact=z.strictObject({
 email:z.email().transform(x=>x.toLowerCase()),
 age:z.coerce.number().int().min(18),
});
type BrowserInput=z.input<typeof Contact>; // age can be unknown
type Validated=z.output<typeof Contact>; // age: number
const result=Contact.safeParse({email:'A@B.COM',age:'22'});
// Avoid z.coerce.boolean() on browser form strings: Boolean('false') is true.
```

**Security and operations:** Never log raw rejected payloads, secrets or personal data. Validate again at server boundaries; a browser schema is for usability, not authorization.

</LessonStep>
