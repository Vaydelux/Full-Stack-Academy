## The problem we're solving

An application expects a Transition to finish synchronously and reads a newly scheduled state value immediately after calling its setter. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Concurrent React can interrupt or abandon non-urgent render work. State setters schedule work and do not mutate render snapshots; transitions keep urgent interactions responsive. Never depend on exact render counts or immediate setter visibility.

**Predict before running:** The repaired implementation respects its documented contract.
