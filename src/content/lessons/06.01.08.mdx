## The problem we're solving

A public profile card spreads private account fields into its displayed view model. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Construct a public projection and validate required data; TypeScript annotations do not strip runtime object fields. Use native buttons with a pressed state for interactive actions.

**Predict before running:** The repaired implementation respects its documented contract.
