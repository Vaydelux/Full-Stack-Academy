## The problem we're solving

A route needing Node filesystem APIs is marked for Edge execution and fails when those APIs are unavailable. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Choose runtime based on actual API support, latency and deployment constraints. Node.js supports Node core modules, while Edge has a restricted API surface. Explicitly use the Node runtime for server code requiring filesystem or native packages.

**Predict before running:** The repaired implementation respects its documented contract.
