## The problem we're solving

Edge vs Node runtime can create user-visible reliability or security failures. The starter selects Edge even when the operation requires Node filesystem APIs.

## Build the mental model

Choose Node.js for native modules, filesystem or database dependencies; Edge is suitable only for compatible Web APIs, while Next.js 16 Proxy uses Node. **Expected result:** Native DB and filesystem workloads select Node; Web-only fetch can be Edge-eligible.

Offline tests verify small, deterministic policy models. They cannot establish real HTTP security, deployment compatibility, image loading, environment secrecy or network diagnostics.
