## The problem we're solving

A request utility promises cancellation, timeouts and retry limits but ignores all three when its transport stalls. This lab uses local Node.js timers, Promises and injected mock transport rather than relying on external APIs or a deployed site.

## Build the mental model

A resilient boundary separates transport from policy: inject the fetcher, cap attempts, distinguish HTTP permanent failures from retryable ones, forward an AbortSignal and clean up timers. Promise.race can reject promptly even when a mock transport never settles, though the transport must itself honor signals to release its own resources.

**Predict before running:** The client returns after transient success, stops on 403, times out a stalled transport and rejects cancellation.

<LessonStep number={2} title="Apply the async boundary and handle errors" file="labs/js-resilient-client/starter/solution.mjs" expected={"The client returns after transient success, stops on 403, times out a stalled transport and rejects cancellation."}>

Make the smallest meaningful correction and preserve the `solve` module contract. For transport cases, keep request functions injectable so the same test can simulate success, failure, timeout and cancellation.

```js
export async function solve(fetcher,{attempts=2,timeoutMs=100,signal}={}){if(typeof fetcher!=='function'||!Number.isInteger(attempts)||attempts<1||!Number.isFinite(timeoutMs)||timeoutMs<=0)throw new TypeError('Invalid policy');let last;for(let attempt=1;attempt<=attempts;attempt++){if(signal?.aborted)throw signal.reason??new Error('aborted');const controller=new AbortController();const forward=()=>controller.abort(signal.reason??new Error('aborted'));signal?.addEventListener('abort',forward,{once:true});let timer;try{const aborted=new Promise((_,reject)=>{controller.signal.addEventListener('abort',()=>reject(controller.signal.reason??new Error('aborted')),{once:true});});timer=setTimeout(()=>controller.abort(new Error('timeout')),timeoutMs);const response=await Promise.race([Promise.resolve().then(()=>fetcher({signal:controller.signal,attempt})),aborted]);if(response.ok)return response.data;const error=new Error('HTTP '+response.status);if(response.status<500)throw Object.assign(error,{permanent:true});last=error;}catch(error){if(signal?.aborted||error.permanent)throw error;last=error;}finally{clearTimeout(timer);signal?.removeEventListener('abort',forward);}}throw last;}
```

**Predict before running:** The client returns after transient success, stops on 403, times out a stalled transport and rejects cancellation.

**Why it works:** A resilient boundary separates transport from policy: inject the fetcher, cap attempts, distinguish HTTP permanent failures from retryable ones, forward an AbortSignal and clean up timers. Promise.race can reject promptly even when a mock transport never settles, though the transport must itself honor signals to release its own resources.

**Proof:** Verify that all promises settle and timer/listener cleanup occurs even after failure.

</LessonStep>
