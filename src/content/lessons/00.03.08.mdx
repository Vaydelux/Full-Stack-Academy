## The problem we're solving

A colleague runs Node 22 and pnpm on an npm project requiring Node 24; package-lock.json is missing. 'Works on my machine' is an environment claim, not a reason to rewrite the app.

## Build the mental model

Compare the actual runtime and toolchain against the documented contract: Node major, package manager, lockfile presence and required environment variable names. A variable's presence does not prove its value is correct, and its value should never enter a shared report. First fix the contract, then use a clean locked install and regression tests. Do not copy node_modules between Windows and WSL or upload credentials into a bug report.

**Predict before running:** Changing the React code cannot satisfy a Node engine major mismatch. Fix the runtime and retry the same test.
