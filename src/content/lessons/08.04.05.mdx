## The problem we're solving

The starter forces parallax displacement even when a person requests reduced motion. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Respect reduced-motion preference while preserving state feedback and focus indicators. The UI must not rely on animation to communicate success.

**Expected outcome:** Reduced motion removes displacement; both modes retain visible state changes.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
