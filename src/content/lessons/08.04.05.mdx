## The problem we're solving

A CSS-only entrance animation remains active even when a user has requested reduced motion from the operating system.

## Build the mental model

Nonessential animation should stop or simplify under prefers-reduced-motion. Test both operating-system preferences in real browsers; source-code inspection alone does not establish runtime behavior or layout stability.

**Predict first:** A reduced-motion preference forces the teaching animation duration to zero, while normal mode retains the declared timing.

## Production library pattern

```tsx
/* CSS */
@media (prefers-reduced-motion: reduce) { .decorative-motion { animation: none; transition-duration: 0ms; } }
```

The CSS pattern is not compiled in the React SSR lab; a real browser must measure actual media-query behavior.
