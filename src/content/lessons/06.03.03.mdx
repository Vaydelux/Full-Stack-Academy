## The problem we're solving

An interval subscription leaks on each remount because the effect never clears its timer. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Effects should return a cleanup function to release resources such as timers, subscriptions and event listeners. React may call setup and cleanup more than once in development to expose unsafe lifecycle assumptions.

**Predict before running:** The repaired implementation respects its documented contract.
