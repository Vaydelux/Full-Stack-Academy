## The problem we're solving

A dashboard schedules recurring work but still receives callbacks after its corresponding React component unmounts. The starter starts an interval and returns an empty cleanup function, leaving background callbacks active. The goal is to learn the React runtime contract rather than memorize hook names.

## Build the mental model

Own the full setup/cleanup lifecycle of a timer or subscription. Before rerunning an Effect whose dependencies changed and again after unmounting the component. **Distinguish source-level correctness from runtime evidence:** Pure helpers can be tested without a browser, but an SSR output assertion cannot prove that an Effect ran, a ref focused an actual input or a global listener was removed after unmount.

**Predict before you run:** Cleanup stops exactly the timer that setup created without disturbing other timers.

import {useEffect,useState} from 'react';
export type Clock={start:(tick:()=>void,ms:number)=>number;stop:(id:number)=>void};
export function startHeartbeat(clock:Clock,onTick:()=>void) {
 const id=clock.start(onTick,1000);
