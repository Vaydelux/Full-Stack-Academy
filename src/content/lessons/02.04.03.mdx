## The problem we're solving

A notification animates width and height, shifting neighboring content during its entrance. A code review should require a reproducible symptom and realistic verification, not only a polished image. The local fixture is synthetic, deterministic and offline.

## Build the mental model

Animating transform and opacity often avoids layout shifts from animating intrinsic size; GPU compositing is an implementation detail, not a universal guarantee. Keep transitions short, test reduced-motion preference and avoid indiscriminate will-change, which can consume memory and extra layers.

**Predict before running:** The toast uses opacity and transform state changes without changing its declared width.
