## The problem we're solving

A team declares a cache hit based on a fast response without recording any evidence of freshness or invalidation. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Investigate cache behavior with explicit headers, instrumentation, controlled repeat requests and the actual configured Cache Components model. Separate client router cache, data cache, full route output and CDN behavior; a synthetic cache classification helper is only one debugging tool.

**Predict before running:** The repaired implementation respects its documented contract.
