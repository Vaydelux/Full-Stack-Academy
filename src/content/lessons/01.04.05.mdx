## The problem we're solving

A page copies content as soon as it loads and declares success even in denied browsers. Some capabilities require secure contexts and transient user activation; a denied permission is not a programming exception to hide. We will request copying only when a learner presses a native button.

## Build the mental model

Browser permissions and capabilities vary across origins, devices, enterprise policies and activation contexts. Clipboard writeText commonly requires a secure context and user interaction. Feature detection is necessary but not sufficient: methods can still reject. A good fallback exposes the text and tells the user to select it manually instead of claiming automatic copying happened.

**Predict before running:** On unsupported or restricted file:// tutorial contexts, clicking Copy safe sample may show a manual-copy explanation, but it must never claim a successful clipboard write.

<LessonStep number={2} title={"Request only on a user gesture"} file="labs/web-permissions/starter/index.html" expected={"No permission prompt happens when the page loads."}>

Put the clipboard attempt inside a native click event and test support.

```js
button.addEventListener('click', async () => {
  if (!navigator.clipboard?.writeText) {
    status.textContent = 'Select the sample and copy manually.';
    return;
  }
});
```

**Predict before running:** No permission prompt happens when the page loads.

**Why it works:** An explicit button allows the browser to associate the request with user activation.

**Proof it works:** Reload: the status should remain neutral until Copy safe sample is pressed.

</LessonStep>


<LessonStep number={3} title={"Handle rejection truthfully"} file="labs/web-permissions/starter/index.html" expected={"Only fulfilled clipboard writes are reported as copied."}>

Catch permission errors and leave a reachable manual fallback.

```js
try {
  await navigator.clipboard.writeText(sample);
  status.textContent = 'Copied the sample text.';
} catch {
  status.textContent = 'Clipboard unavailable. Select the sample and copy manually.';
}
```

**Predict before running:** Only fulfilled clipboard writes are reported as copied.

**Why it works:** Denied permission is an expected result and should not break the page.

**Proof it works:** Click Copy safe sample; verify that either branch remains usable.

</LessonStep>
