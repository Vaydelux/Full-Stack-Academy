## The problem we're solving

Removing the first roster row causes later stateful rows to use keys from old positions. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Stable unique keys tell React which sibling represents which domain object. Index-based keys break state identity when a list is reordered or filtered.

**Predict before running:** The repaired implementation respects its documented contract.
