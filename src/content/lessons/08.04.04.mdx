## The problem we're solving

The starter labels every issue low-priority even if it blocks the primary task. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Prioritize usability findings by impact and recurrence, record evidence and map fixes to the user journey rather than subjective visual preference.

**Expected outcome:** A recurring blocker ranks higher than a minor cosmetic issue, with reproducible scoring.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
