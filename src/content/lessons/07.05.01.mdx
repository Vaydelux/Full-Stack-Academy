## The problem we're solving

A server API secret is placed under a NEXT_PUBLIC variable and copied into an environment file intended for client builds. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Separate development, preview and production environments; expose only intentionally public settings with NEXT_PUBLIC. Server secrets should be accessed only from trusted server code, rotated after accidental exposure and never written into pages or diagnostic logs.

**Predict before running:** The repaired implementation respects its documented contract.
