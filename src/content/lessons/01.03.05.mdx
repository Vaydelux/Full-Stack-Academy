## The problem we're solving

A pale cyan label looks attractive against white but is difficult to read. Someone tries to fix it by adding a shadow without measuring contrast and declares the design accessible.

## Build the mental model

WCAG 2.2 SC 1.4.3 has a minimum 4.5:1 contrast for ordinary text and 3:1 for large-scale text, with specified exceptions. Large-scale text means at least 18pt or 14pt bold in CSS terms (roughly 24px or about 18.66px bold at 96dpi). Required non-text UI indicators and graphics have other criteria such as 1.4.11. Relative luminance uses gamma-corrected sRGB values; a naive arithmetic average of RGB channels is wrong. This exercise handles **opaque six-digit hex colors only**, not transparency, gradients, dynamic backgrounds or a full page audit. A passing pair does not establish WCAG conformance.

**Predict before running:** Pure black (#000000) against white (#ffffff) is 21:1, not 1:1. A gray around #777777 on white is just under the 4.5:1 normal-text threshold.

<LessonStep number={1} title={"Convert sRGB channel values to linear light"} file="labs/a11y-contrast/starter/index.html" expected={"The normalized channel values represent relative linear light."}>

Parse a strict six-digit color and apply the sRGB transfer function, not a simple RGB average.

```js
const linear=v=>v<=0.04045?v/12.92:((v+0.055)/1.055)**2.4;
// For #ffffff, each channel is 1; for #000000, each channel is 0.
```

</LessonStep>

<LessonStep number={2} title={"Compute relative luminance and contrast"} file="labs/a11y-contrast/starter/index.html" expected={"Black/white produces 21:1; the order of the colors does not matter."}>

Weight the corrected channels and compare lighter and darker luminance with the 0.05 offset.

```js
const luminance=(r,g,b)=>0.2126*r+0.7152*g+0.0722*b;
const ratio=(light,dark)=>(Math.max(light,dark)+0.05)/(Math.min(light,dark)+0.05);
```

</LessonStep>

<LessonStep number={3} title={"Provide a bounded interactive checker"} file="labs/a11y-contrast/starter/index.html" expected={"The calculator shows a measured ratio and qualified text thresholds."}>

Show whether the pair meets 4.5:1 ordinary-text and 3:1 large-text thresholds; disclose limited scope.

```js
const value=contrastRatio('#000000','#ffffff');
console.log(value.toFixed(2)); // 21.00
// Only opaque six-digit hex colors are supported.
```

</LessonStep>
