## The problem we're solving

A response cache uses only a route path as a key for two different authenticated users, risking cross-account data exposure. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Never share authenticated response data under a global cache key. Scope identity and tenancy precisely or avoid caching private responses; authorization must happen on every protected access path. Varying a UI element is not a substitute for cache partitioning.

**Predict before running:** The repaired implementation respects its documented contract.
