## The problem we're solving

An automated audit labels placeholder pages as indexable and ignores missing titles and inconsistent canonical URLs. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A useful SEO release gate checks published status, indexing directives, canonical URL consistency and semantic metadata together. Static checks cannot establish actual rankings or Search Console status, so follow with a hosted crawl after deployment is authorized.

**Predict before running:** The repaired implementation respects its documented contract.

Make the smallest semantic correction; do not weaken the assertions or convert invalid data into a fake success.

```ts

export function solve(page:{published:boolean;title:string;canonical:string}){const issues:string[]=[];if(!page.published)issues.push('not-published');if(page.title.trim().length<3)issues.push('missing-title');if(!/^https:\/\//.test(page.canonical))issues.push('invalid-canonical');return {index:page.published&&issues.length===0,issues};}

```

**Why it works:** A useful SEO release gate checks published status, indexing directives, canonical URL consistency and semantic metadata together. Static checks cannot establish actual rankings or Search Console status, so follow with a hosted crawl after deployment is authorized.

**Proof:** Run the same local assertions and compare the before/after outputs.

</LessonStep>
