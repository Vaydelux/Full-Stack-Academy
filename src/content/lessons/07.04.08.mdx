## The problem we're solving

The team prepares a release with published and draft content, but an audit needs to flag missing descriptions, duplicate canonicals and draft indexing.

**Defect:** The starter always reports no SEO issues, even for a visible draft with duplicate canonical.

## Build the mental model

Audit indexability, canonical uniqueness and required metadata before treating a page as a published search result.

**Predict before running:** Draft marked indexable and published entries missing canonical or description generate explicit issues.

The academy exercises reviewed TypeScript/React logic locally. It does not automatically exercise the Next.js Metadata API, search crawler, browser page loading, network waterfall, Lighthouse or real-user field metrics. Those are separate qualification gates.

<LessonStep number={2} title="Repair the measurable contract" file="labs/next-seo-audit-capstone/starter/solution.tsx" expected="Draft marked indexable and published entries missing canonical or description generate explicit issues.">

```tsx
export type Page={id:string;published:boolean;index:boolean;canonical:string;description:string};
export function auditPages(pages:readonly Page[]):string[]{
 const issues:string[]=[];const canonical=new Set<string>();
 for(const page of pages){
  if(!page.published&&page.index)issues.push(page.id+':draft-indexed');
  if(page.published&&page.index){
   if(!page.description.trim())issues.push(page.id+':missing-description');
   if(!page.canonical.startsWith('https://'))issues.push(page.id+':invalid-canonical');
   if(canonical.has(page.canonical))issues.push(page.id+':duplicate-canonical');
   canonical.add(page.canonical);
  }
 }
 return issues;
}
```

**Root principle:** Audit indexability, canonical uniqueness and required metadata before treating a page as a published search result.

</LessonStep>

// Release audit, local only:

**Production nuance:** This auditing model detects selected metadata errors, not actual browser/crawler behavior or Search Console results. Combine it with a real Next production build and locally served route checks.
