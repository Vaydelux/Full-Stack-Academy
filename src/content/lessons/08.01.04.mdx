## The problem we're solving

A shared button swallows the disabled state and unintentionally submits every form because the native button type is omitted.

## Build the mental model

shadcn/ui installs component source into your application, where composition and ownership remain yours. Keep native button semantics (type, disabled, accessible names) and choose the current primitive implementation deliberately instead of treating copied components as an opaque hosted service.

**Predict first:** The button is a non-submitting native control with a disabled state tied to pending work.

## Production library pattern

```tsx
"use client";
import {Button} from "@/components/ui/button";
function SaveAction({pending}:{pending:boolean}){return <Button type="button" disabled={pending} aria-label={pending?"Saving profile":"Save profile"}>{pending?"Saving…":"Save"}</Button>;}
```

The import assumes you have intentionally added a shadcn Button source file. This snippet is illustrative; the offline lab verifies only the native equivalent.
