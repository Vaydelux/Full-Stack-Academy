## The problem we're solving

The adapter plan always imports Radix, even for Base UI setups. A robust component system has to work across dark and light themes, keyboard input, small screens and real data, not merely appear correct in a screenshot.

## Build the mental model

shadcn components are owned source; match your installed Base UI or Radix adapter rather than assuming Radix is universal. **Predict before executing:** Base UI and Radix produce different explicit package dependencies.

**Runtime boundary:** This lesson's fixture is local TypeScript only. It does not compile Tailwind CSS, install shadcn or Radix/Base UI, mount a browser interaction, or verify visual contrast on real content. Those require a dedicated UI build and accessibility checks.
