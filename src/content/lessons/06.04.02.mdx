## The problem we're solving

Two search components normalize text differently and duplicate state synchronization code. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A custom Hook extracts reusable stateful behavior and must follow the Rules of Hooks. Its name begins with use and it calls other Hooks unconditionally at the top level. Share logic, not accidentally one mutable state instance across unrelated components.

**Predict before running:** The repaired implementation respects its documented contract.
