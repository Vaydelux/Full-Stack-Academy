## The problem we're solving

Three disclosure panels duplicate the same open/close state and callbacks, making their behavior diverge. The starter's toggle utility never changes the boolean, so every consumer remains stuck in its initial state.

## Build the mental model

Package a reusable stateful behavior in a custom Hook while keeping the caller's UI independent. A function whose name starts with use and that uses React Hooks under the same top-level call rules. The React 19 APIs used here have distinct contracts: context passes values, transitions schedule nonurgent updates, deferred values let rendering lag, and optimistic state is a temporary view during an Action. These lessons use local data, not backend persistence.

**Predict before you run:** Toggling either boolean changes its value, and a fresh disclosure starts in its explicit initial state.

The instructor repair preserves the public exports while fixing the value propagation, scheduling, or state reconciliation defect:

```tsx
import {useState} from 'react';
export function inverted(value:boolean){return !value;}
export function useDisclosure(initial=false){
 const [open,setOpen]=useState(initial);
 return {open,toggle:()=>setOpen(value=>inverted(value)),close:()=>setOpen(false)};
}
export function Disclosure() {
 const disclosure=useDisclosure(false);
 return <button type="button" aria-expanded={disclosure.open} onClick={disclosure.toggle}>Details</button>;
}
```

**Why it works:** Package a reusable stateful behavior in a custom Hook while keeping the caller's UI independent.
