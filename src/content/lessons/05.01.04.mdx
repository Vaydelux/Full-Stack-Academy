## The problem we're solving

A local branch is committed but the bare local remote has no main ref. This lesson is an offline, repeatable source-control exercise; it never touches the learner's actual project repository or opens a hosted pull request.

## Build the mental model

Remotes are named repositories, not automatic synchronization. git push moves a remote ref after transferring objects, subject to fast-forward and server rules. Set upstream to make future pulls/pushes target the reviewed branch. This lab uses a temporary bare local remote only; no GitHub credentials or network.

**Predict before running:** The local bare remote receives main and the local branch tracks origin/main.

```js
const remoteCheck=git(['ls-remote','origin','refs/heads/main']).stdout;assert.match(remoteCheck,/refs\/heads\/main/);assert.match(git(['rev-parse','--abbrev-ref','main@{upstream}']).stdout,/origin\/main/);
```

**Predict before running:** The corrected command order changes the relevant repository state while preserving the baseline.

**Why it matters:** A green file syntax check cannot prove correct Git commit ancestry, staged file contents or remote refs.
