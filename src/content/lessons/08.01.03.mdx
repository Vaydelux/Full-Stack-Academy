## The problem we're solving

The empty-title dialog is marked accessible. A robust component system has to work across dark and light themes, keyboard input, small screens and real data, not merely appear correct in a screenshot.

## Build the mental model

Radix Dialog requires a named accessible Title, Description and verified focus behavior. **Predict before executing:** A nonempty title and description are required.

**Runtime boundary:** This lesson's fixture is local TypeScript only. It does not compile Tailwind CSS, install shadcn or Radix/Base UI, mount a browser interaction, or verify visual contrast on real content. Those require a dedicated UI build and accessibility checks.
