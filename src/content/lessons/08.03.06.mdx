## The problem we're solving

The starter changes the status of every row, not just the requested record. Enterprise interfaces need correct data scope, stable identities, accessible states and predictable behavior under pagination, refresh and mobile layouts.

## Build the mental model

Show a reversible pending update in a stable row without mutating server-owned data or implying the change has been persisted.

**Prediction:** Only the target row changes, original rows remain unchanged and missing IDs are no-ops.

**Scope of evidence:** The instructor's local Node tests exercise a pure data transformation. TanStack Table v8 and TanStack Virtual require separate dependency installation and mounted browser tests. Never treat sorting the current server page as global sorting, or browser-side role checks as server authorization.
