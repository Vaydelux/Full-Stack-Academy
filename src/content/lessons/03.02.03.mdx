## The problem we're solving

A shared cart method writes into an exposed array, allowing outside callers to change totals without going through validation. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

Classes are syntax over JavaScript's prototype-based method model. Private fields protect instance state at runtime, while methods can enforce invariants. Freezing a returned snapshot prevents accidental external array mutation; it does not freeze arbitrary nested objects.

**Predict before running:** Each Basket owns validated private entries, and callers cannot push directly into its internal array.

