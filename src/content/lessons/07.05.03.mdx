## The problem we're solving

A static asset validator accepts path traversal and unsupported file extensions for a public image URL. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Keep static assets under a controlled public path, validate names, and use image optimization where appropriate. Next Image supports responsive rendering but still depends on valid source configuration and correct alt text. Never allow arbitrary local filesystem paths through user input.

**Predict before running:** The repaired implementation respects its documented contract.
