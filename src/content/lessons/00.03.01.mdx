## The problem we're solving

A page fails with 'Unable to load dashboard,' but the real failure started when configuration was missing. Guessing at the last visible UI symptom wastes effort and encourages random fixes.

## Build the mental model

An Error has a name, message, and usually a stack showing where it was thrown followed by callers. The top stack frame often points closest to the throw; it is not universally the 'bottom line.' An Error.cause chain records higher-level error wrappers; following it toward the deepest cause can reveal the originating failure. Console output order varies by runtime and formatting. Diagnose the cause chain first, identify the first relevant application frame, then reproduce the failure. Never paste logs containing credentials or personal data.

**Predict before running:** If Error('Load failed', {cause:new TypeError('missing config')}) is thrown, which message most directly names the originating failure? 'missing config', while the wrapper provides operation context.

<LessonStep number={2} title={"Trace causes without looping"} file="labs/error-causes/starter/exercise.mjs" expected={"The chain includes wrapper first and deepest originating error last."}>

Implement traceCauses in your starter. Stop after eight levels and track visited errors; Error.cause can be arbitrary and even cyclic.

```js
export function traceCauses(error, maxDepth = 8) {
  const chain = [], seen = new Set();
  let current = error;
  while (current instanceof Error && !seen.has(current) && chain.length < maxDepth) {
    seen.add(current);
    chain.push({ name: current.name, message: current.message });
    current = current.cause;
  }
  return chain;
}
```

</LessonStep>

<LessonStep number={3} title={"Select a useful application frame"} file="labs/error-causes/starter/exercise.mjs" expected={"A matching lab frame is returned; a stack containing only Node internals returns null."}>

A stack entry is a formatted string, not a reliable structured API. For this exercise, locate a line containing a lab path; return null if no such frame appears.

```js
export function firstLabFrame(stack) {
  return String(stack ?? '').split('\n').slice(1)
    .map(line => line.trim())
    .find(line => line.includes('/labs/') || line.includes('\\labs\\')) ?? null;
}
```
