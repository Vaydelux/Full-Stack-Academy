## The problem we're solving

A page swaps typefaces and expands its heading area, while an image placeholder has no reserved height. A code review should require a reproducible symptom and realistic verification, not only a polished image. The local fixture is synthetic, deterministic and offline.

## Build the mental model

Layout shift can arise when web fonts change text metrics or media takes space after loading. font-display controls the font-loading swap behavior for @font-face; optional can avoid a late font replacement but might preserve fallback text. Size media explicitly and choose compatible fallback metrics; real CLS must be measured with performance tools, not claimed from one CSS rule.

**Predict before running:** The media area reserves a 16:9 box and the heading has a deliberate fallback font/line-height policy.

## Explore and verify

Use DevTools to inspect computed styles and the Performance recording when making speed claims. Not every transform is composited; not every font loading strategy removes CLS; not every visually distinct control is accessible. The Node tests check instructor patterns; the isolated browser suite observes representative states. Manual assistive-technology and cross-browser checks remain outside the automated guarantee.
