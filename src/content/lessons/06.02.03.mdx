## The problem we're solving

A shopping summary duplicates a total and forgets to update it after a line item quantity changes. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

If a value can be derived from current props or state, calculate it during render rather than keeping a second writable copy that may drift. Memoization is optional and justified by measured cost, not required for basic arithmetic.

**Predict before running:** The repaired implementation respects its documented contract.
