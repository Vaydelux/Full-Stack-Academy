## The problem we're solving

A sortable form list assigns random keys on each render, causing local input state and focus to reset unexpectedly. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Keys identify sibling component instances. Generate stable IDs when records are created, not during render; changing an element's key intentionally resets its state. Unstable keys can cause accessibility and data-loss bugs.

**Predict before running:** The repaired implementation respects its documented contract.
