## The problem we're solving

A page with per-request account details is treated as an indefinitely cached static page. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Static rendering suits public content with known freshness requirements; request-time rendering handles personalized data; incremental regeneration suits public pages where bounded staleness is acceptable. With Cache Components, configure explicit cached scopes rather than relying on old global defaults.

**Predict before running:** The repaired implementation respects its documented contract.
