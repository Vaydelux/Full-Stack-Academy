## The problem we're solving

A user-specific fetch is accidentally cached as though it contained public catalog content. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Make fetch caching policy explicit and version-aware. With Next.js 16 Cache Components, caching is opt-in through a supported use cache boundary; older App Router cache behavior differs. Private request-bound data should not enter shared caches.

**Predict before running:** The repaired implementation respects its documented contract.
