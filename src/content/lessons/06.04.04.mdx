## The problem we're solving

An expensive result list recomputes on each keystroke at the same priority as the input field. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

useDeferredValue lets a part of the UI lag behind a rapidly changing value while the urgent input remains current. It does not debounce network requests on its own. Show a stale-results cue if the deferred result differs from current input.

**Predict before running:** The repaired implementation respects its documented contract.
