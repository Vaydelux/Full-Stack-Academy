## The problem we're solving

A draft note disappears on refresh and the UI never distinguishes browser persistence from in-memory state. Browser Interaction topics require both executable JavaScript logic and a real local HTML document. The fixture uses synthetic content with no external scripts, endpoints or data uploads.

## Build the mental model

localStorage is synchronous string storage, while IndexedDB supports asynchronous structured object records and transactions. Both are origin-scoped and may be unavailable in private or file contexts. Catch storage exceptions and provide a clear in-memory fallback; never store secrets or assume cross-device sync.

**Predict before running:** Saving reports whether localStorage, IndexedDB or memory fallback was available without making a remote request.

<LessonStep number={2} title="Implement the browser-safe interaction" file="labs/js-storage/starter/index.html" expected={"Saving reports whether localStorage, IndexedDB or memory fallback was available without making a remote request."}>

Replace the defective handler without discarding native elements or semantics. For untrusted content use `textContent`, not an unsafe HTML sink.

```js
document.querySelector('#save').addEventListener('click',async()=>{const value=document.querySelector('#note').value;let mode='memory';try{localStorage.setItem('academy-note',value);mode='localStorage';}catch{}if('indexedDB' in window){try{await new Promise((resolve,reject)=>{const request=indexedDB.open('academy-course-demo',1);request.onupgradeneeded=()=>{request.result.createObjectStore('notes');};request.onerror=()=>reject(request.error);request.onsuccess=()=>{const db=request.result;const tx=db.transaction('notes','readwrite');tx.objectStore('notes').put(value,'note');tx.oncomplete=()=>{db.close();resolve();};tx.onerror=()=>{db.close();reject(tx.error);};};});mode+=' + IndexedDB';}catch{}}document.querySelector('#status').textContent='Stored using '+mode+' (this browser only).';});
```

**Predict before running:** Saving reports whether localStorage, IndexedDB or memory fallback was available without making a remote request.

**Why the repair works:** localStorage is synchronous string storage, while IndexedDB supports asynchronous structured object records and transactions. Both are origin-scoped and may be unavailable in private or file contexts. Catch storage exceptions and provide a clear in-memory fallback; never store secrets or assume cross-device sync.

**Proof:** Compare the resulting DOM and accessibility state to the instructor `solution/index.html` using the same input.

</LessonStep>
