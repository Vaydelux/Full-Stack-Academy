## The problem we're solving

An update helper mutates the caller's original array and returns the same object reference, hiding the change from identity-based comparisons. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Treat arrays and objects stored in React state as immutable. Map to a new array and spread only the changed record. Deep nested structures need copies at every modified level, or a carefully chosen reducer abstraction.

**Predict before running:** The repaired implementation respects its documented contract.
