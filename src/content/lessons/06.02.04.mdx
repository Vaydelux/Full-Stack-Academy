## The problem we're solving

A quantity editor must update one cart row without mutating the previous state snapshot. Directly changing an array item mutates past snapshots and defeats predictable React updates. The following exercise is React 19 and TypeScript 5 source checked into this repository, not a remote code runner.

## Build the mental model

Use immutable updates so unchanged items preserve identity while the modified record receives a new object. Map to a new array and clone only the record that changes. **Important boundary:** A pure-function test validates state transitions and static React rendering checks initial markup; neither alone simulates an interactive browser or verifies hydration and effect behavior.

**Predict before you run:** Only the selected item changes; the previous list and untouched item references remain intact.

export type QuantityRow={id:string;quantity:number};
export function setQuantity(rows:readonly QuantityRow[],id:string,quantity:number):QuantityRow[] {
 if(!Number.isSafeInteger(quantity)||quantity<0) throw new RangeError('Invalid quantity');
 return rows.map(row=>row.id===id?{...row,quantity}:row);
}
export function QuantityList({rows}:{rows:readonly QuantityRow[]}) {
