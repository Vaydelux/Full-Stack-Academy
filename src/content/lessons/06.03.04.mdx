## The problem we're solving

A team member switches between chat rooms but their status continues receiving events from a previously selected room. The starter subscribes to a hardcoded room instead of the current roomId. The goal is to learn the React runtime contract rather than memorize hook names.

## Build the mental model

Treat subscription dependencies as part of the synchronization contract. Every reactive value read by the Effect, as enforced by the React Hooks lint rule. **Distinguish source-level correctness from runtime evidence:** Pure helpers can be tested without a browser, but an SSR output assertion cannot prove that an Effect ran, a ref focused an actual input or a global listener was removed after unmount.

**Predict before you run:** Subscription uses the current room ID and returns the correct room-scoped cleanup.

import {useEffect,useState} from 'react';
export type RoomBus={subscribe:(room:string,listener:()=>void)=>()=>void};

 if(!roomId.trim()) return ()=>{};

 useEffect(()=>connectRoom(roomId,bus,()=>setMessages(n=>n+1)),[roomId,bus]);
