## The problem we're solving

An effect does not refresh a result when the query changes because it uses an empty dependency list. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

List every reactive value used by an Effect in its dependency array. React compares dependencies using Object.is. Do not disable the exhaustive-deps lint rule to hide stale data; move nonreactive logic outside the Effect when appropriate.

**Predict before running:** The repaired implementation respects its documented contract.
