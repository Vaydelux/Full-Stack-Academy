## The problem we're solving

An autocomplete highlights the first item but commits a different record when the filtered list changes, because the selection is tracked by index.

## Build the mental model

Represent suggestions with stable option IDs and a typed query; the active descendant must identify an option still present in the current list. Full ARIA combobox keyboard behavior is demanding: prefer a tested primitive or native datalist when requirements permit.

**Predict first:** Only matching stable option IDs remain available after filtering; active selection must be reconciled separately.

## Production library pattern

```tsx
"use client";
import * as Select from "@radix-ui/react-select";
function FruitSelect(){return <Select.Root><Select.Trigger aria-label="Fruit"><Select.Value placeholder="Select fruit"/></Select.Trigger><Select.Portal><Select.Content><Select.Viewport><Select.Item value="apple"><Select.ItemText>Apple</Select.ItemText></Select.Item></Select.Viewport></Select.Content></Select.Portal></Select.Root>;}
```

The Radix Select pattern is not a full free-text combobox. For searchable combobox behavior, choose a corresponding primitive and test typeahead, focus, and announcements separately.
