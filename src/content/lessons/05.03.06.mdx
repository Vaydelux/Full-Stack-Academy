## The problem we're solving

A package version changes but a lock snapshot still lists an older dependency, and the workspace reports reproducibility anyway. This offline workshop is part of the Git/monorepo track; no workspace installation, external package query or Vercel build runs when reading the lesson.

## Build the mental model

A committed pnpm-lock.yaml records resolved package dependency metadata for reproducible installs. pnpm install --frozen-lockfile should reject manifest/lockfile mismatches in CI. This simplified structured snapshot validates exact direct-dependency consistency; it is not a full pnpm lockfile parser or supply-chain audit.

**Predict before running:** The policy fails on stale, missing or additional direct dependency pins, even though the snapshot is not a real lock parser.

<LessonStep number={2} title="Repair the explicit workspace contract" file="labs/mono-lockfile/starter/solution.mjs" expected={"The policy fails on stale, missing or additional direct dependency pins, even though the snapshot is not a real lock parser."}>

Preserve the exported `solve` entry and implement the smallest correct policy, noting whether this example is a simplified model rather than an actual pnpm/turbo invocation.

```js
export function solve(manifest,lock){if(!manifest||!lock||typeof manifest!=='object'||typeof lock!=='object')return false;const direct={...manifest.dependencies,...manifest.devDependencies};return Object.keys(direct).length===Object.keys(lock).length&&Object.entries(direct).every(([name,version])=>lock[name]===version);}
```

**Predict before running:** The policy fails on stale, missing or additional direct dependency pins, even though the snapshot is not a real lock parser.

**Why the repair works:** A committed pnpm-lock.yaml records resolved package dependency metadata for reproducible installs. pnpm install --frozen-lockfile should reject manifest/lockfile mismatches in CI. This simplified structured snapshot validates exact direct-dependency consistency; it is not a full pnpm lockfile parser or supply-chain audit.
