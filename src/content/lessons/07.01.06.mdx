## The problem we're solving

A documentation link accepts a path for a known same-origin page, but arbitrary external and JavaScript URLs must not become in-app navigation targets.

**Failure:** The starter returns any supplied destination unchanged, including external origins.

## Build the mental model

Keep navigation internal and explicit; use next/link for user navigation and do not turn untrusted destinations into open redirects.

**Prediction:** A local guide path remains internal; cross-origin and non-HTTP schemes are rejected.

**Proof boundary:** The local Node/TSX fixture verifies this lesson's deterministic model and initial React markup. It does **not** start Next.js, compile route conventions, simulate streaming, or prove HTTP status codes. A separately built Next application and browser/HTTP test are needed before release qualification.

<LessonStep number={2} title="Implement the safe Next.js-oriented contract" file="labs/next-navigation-prefetch/starter/solution.tsx" expected="A local guide path remains internal; cross-origin and non-HTTP schemes are rejected.">

```tsx
export function safeInternalPath(destination:string){
 if(!destination.startsWith('/')||destination.startsWith('//'))return null;
 try{
  const parsed=new URL(destination,'https://academy.invalid');
  if(parsed.origin!=='https://academy.invalid')return null;
  if(parsed.pathname.startsWith('/\\'))return null;
  return parsed.pathname+parsed.search+parsed.hash;
 }catch{return null;}
}
export function NavPath({destination}:{destination:string}){
 const href=safeInternalPath(destination);
 return <code>{href??'Invalid destination'}</code>;
}
```

**Why it works:** Keep navigation internal and explicit; use next/link for user navigation and do not turn untrusted destinations into open redirects.

</LessonStep>

**Real App Router shape:**

```tsx
import Link from 'next/link';
export default function GuideNav() {
  return <nav aria-label="Guide navigation">
    <Link href="/guides/react">React guide</Link>
    <Link href="/guides/nextjs" prefetch={false}>Next.js guide</Link>
  </nav>;
}
```

**Nuance:** Next.js may prefetch visible links depending on deployment and route context. This is a performance feature, not an authorization check or guarantee the destination is available offline. Internal href validation is separate from server access control.

</LessonStep>
