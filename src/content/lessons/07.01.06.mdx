## The problem we're solving

A route link is implemented with window.location, forcing full reloads and losing client-side navigation benefits. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Next.js Link supports client-side navigation and optional prefetch when appropriate. Programmatic navigation belongs in useRouter inside a Client Component. Disable prefetch selectively for expensive or sensitive paths, not blindly for every link.

**Predict before running:** The repaired implementation respects its documented contract.
