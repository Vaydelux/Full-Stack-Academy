## The problem we're solving

A product subtotal is mirrored in state through an Effect, resulting in an extra render and transient stale output. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

If a value is deterministically derived from current inputs, compute it during render. Effects are intended for external synchronization, not ordinary transformations or event reactions that can be handled directly.

**Predict before running:** The repaired implementation respects its documented contract.
