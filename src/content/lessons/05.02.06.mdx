## The problem we're solving

A version calculator treats every change as a patch, even when an incompatible API is removed. The lesson uses synthetic local data; passing its test does not configure actual branch protection or trigger a release.

## Build the mental model

Semantic Versioning expresses MAJOR.MINOR.PATCH for incompatible API changes, backward-compatible functionality and bug fixes respectively. Pre-1.0 has different stability expectations, so this lab explicitly models stable 1.0+ versions only and rejects ambiguous pre-release strings.

**Predict before running:** Breaking changes bump the major, new compatible features bump minor, and fixes bump patch.

<LessonStep number={2} title="Implement the explicit review or release contract" file="labs/team-semver/starter/solution.mjs" expected={"Breaking changes bump the major, new compatible features bump minor, and fixes bump patch."}>

Prefer an explicit result and a narrow, auditable policy; do not invent remote approvals or call an external API.

```js
export function solve(version,change){if(typeof version!=='string'||!['breaking','feature','fix'].includes(change)||!/^\d+\.\d+\.\d+$/.test(version))throw new TypeError('Stable semver and change required');const [major,minor,patch]=version.split('.').map(Number);if(major<1||![major,minor,patch].every(Number.isSafeInteger))throw new RangeError('Stable major >=1 required');return change==='breaking'?((major+1)+'.0.0'):change==='feature'?(major+'.'+(minor+1)+'.0'):(major+'.'+minor+'.'+(patch+1));}
```

**Predict before running:** Breaking changes bump the major, new compatible features bump minor, and fixes bump patch.

**Why the repair works:** Semantic Versioning expresses MAJOR.MINOR.PATCH for incompatible API changes, backward-compatible functionality and bug fixes respectively. Pre-1.0 has different stability expectations, so this lab explicitly models stable 1.0+ versions only and rejects ambiguous pre-release strings.

**Proof:** Run the same independent test after editing; a green result demonstrates this local policy only.

</LessonStep>

<LessonStep number={3} title="Test both positive and negative outcomes" file="labs/team-semver/solution.test.mjs" expected="Passes a precise expected-output contract and rejects a misleading or invalid case.">

assert.equal(solve('1.4.2','breaking'),'2.0.0');assert.equal(solve('1.4.2','feature'),'1.5.0');assert.equal(solve('1.4.2','fix'),'1.4.3');assert.throws(()=>solve('0.5.0','breaking'),RangeError);
