## The problem we're solving

A Client Component imports a server secret accessor and risks bundling server-only logic into the browser graph. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

The use client directive marks a module as a client entry point and makes its imports part of the client graph. Keep server-only modules outside that graph, and pass explicit public DTOs through props. Never rely on tree-shaking as a security boundary.

**Predict before running:** The repaired implementation respects its documented contract.
