## The problem we're solving

A theme uses 11px text for essential instructions and relies on low contrast to distinguish secondary content.

## Build the mental model

Typography must remain legible when zoomed; use scalable units, sufficient contrast, a readable line height and a clear hierarchy. A token system prevents different pages from silently drifting into tiny arbitrary values.

**Predict first:** The teaching baseline rejects negative sizes and lifts the 11px body copy to a 16px token.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-typography-system/starter/solution.ts" expected="The teaching baseline rejects negative sizes and lifts the 11px body copy to a 16px token.">

```ts

export function solve(size:number):number{if(!Number.isFinite(size)||size<0)throw new TypeError("Invalid font size");return Math.max(16,size);}

```

**Why it works:** Typography must remain legible when zoomed; use scalable units, sufficient contrast, a readable line height and a clear hierarchy. A token system prevents different pages from silently drifting into tiny arbitrary values.

**Proof:** Run `npm run lab:ui-typography-system` and inspect the instructor test output.

</LessonStep>
