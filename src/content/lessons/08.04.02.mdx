## The problem we're solving

The starter maps every role to body text, flattening visual hierarchy. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Use semantic typography roles, a bounded scale and foreground/background combinations that remain legible in light and dark themes.

**Expected outcome:** Heading and body map to distinct token pairs and small labels retain appropriate contrast.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
