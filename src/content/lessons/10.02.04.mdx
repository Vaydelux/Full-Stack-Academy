## The problem we're solving

A client retries POST after losing a response; without deduplication the API creates two payments or jobs.

**Fault to find:** The starter runs the business operation on every retry, producing duplicate effects. This track uses Node 24 built-ins and fetch-compatible `Response` where appropriate; no paid platform or remote arbitrary-code execution is needed.

## Build the mental model

Tie an idempotency key to the request fingerprint and in-flight promise; replay the same result, reject changed payloads and remove failed attempts.

**Expected repair:** Concurrent same-key requests execute once; a changed payload with the same key produces a conflict.

HTTP semantics follow RFC 9110. Public errors can use RFC 9457 Problem Details; do not invent return codes or copy internal stack traces into public responses. Pure helper tests are useful but the final capstone runs a real loopback server and tests wire responses.

<LessonStep number={2} title="Implement standards-based HTTP behavior" file="labs/http-idempotency-retry/starter/solution.mjs" expected="Concurrent same-key requests execute once; a changed payload with the same key produces a conflict.">

```js
import {createHash} from 'node:crypto';
export function makeIdempotent(run){
 const records=new Map();
 return async(key,payload)=>{
  if(typeof key!=='string'||!/^[A-Za-z0-9_-]{1,64}$/.test(key))throw new TypeError('Invalid idempotency key');
  const fingerprint=createHash('sha256').update(JSON.stringify(payload)).digest('hex');
  const existing=records.get(key);
  if(existing){
   if(existing.fingerprint!==fingerprint)return {status:409,conflict:true};
   return existing.promise;
  }
  const promise=Promise.resolve().then(()=>run(payload));
  records.set(key,{fingerprint,promise});
  try{return await promise;}catch(error){records.delete(key);throw error;}
 };
}
```

**Why this is correct:** Tie an idempotency key to the request fingerprint and in-flight promise; replay the same result, reject changed payloads and remove failed attempts.

</LessonStep>
