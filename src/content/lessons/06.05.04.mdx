## The problem we're solving

A performance dashboard labels every render as a bottleneck without measuring or grouping actual render durations. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React Profiler reports timing for measured commits; DevTools helps locate slow renders. Record actual measurements under representative workloads instead of declaring fixed millisecond results. Development profiling and production behavior can differ.

**Predict before running:** The repaired implementation respects its documented contract.
