## The problem we're solving

The publish action invalidates the cache before validating the article, then announces success for an invalid draft. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Mutation order matters: authenticate, authorize, validate, persist, then invalidate the smallest affected cache scope. React UI optimism is not persistence proof. Use updateTag in Server Actions for immediate consistency when Cache Components is configured.

**Predict before running:** The repaired implementation respects its documented contract.
