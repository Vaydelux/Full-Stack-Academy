## The problem we're solving

Deduplication by JSON stringification accidentally merges different object identities and loses useful tag counts. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

Map keys can be arbitrary values; Set keeps unique values; WeakSet and WeakMap hold object identities without preventing collection. Weak collections are not enumerable; use Map for enumerable reports and WeakSet for identity-only visited tracking.

**Predict before running:** Repeated references are ignored, but distinct objects with the same content remain distinct.

<LessonStep number={2} title="Repair the semantic boundary" file="labs/js-map-set/starter/solution.mjs" expected={"Repeated references are ignored, but distinct objects with the same content remain distinct."}>

Implement the corrected behavior using the relevant lexical, prototype, module or copying rule. Preserve the named `solve` export.

```js
export function solve(rows){const seen=new WeakSet(),counts=new Map(),tags=new Set();for(const row of rows){if(!row||typeof row!=='object')throw new TypeError('Rows must be objects');if(seen.has(row))continue;seen.add(row);const tag=String(row.tag);tags.add(tag);counts.set(tag,(counts.get(tag)||0)+1);}return {tags:[...tags],counts:Object.fromEntries(counts)};}
```

**Predict before running:** Repeated references are ignored, but distinct objects with the same content remain distinct.

**Why the repair works:** Map keys can be arbitrary values; Set keeps unique values; WeakSet and WeakMap hold object identities without preventing collection. Weak collections are not enumerable; use Map for enumerable reports and WeakSet for identity-only visited tracking.

**Proof:** Compare independent instances, object identity or errors under the same test file.

</LessonStep>
