## The problem we're solving

A form reducer accepts submit events before any input has been validated, entering a success state with empty data. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A reducer maps previous state and an action into a new state. Discriminated action variants make allowed transitions explicit and enable exhaustive handling. Reducers should remain pure and not mutate state or perform network calls.

**Predict before running:** The repaired implementation respects its documented contract.
