## The problem we're solving

An Add Two button must increment exactly twice even when React batches updates from one event. Two calls with the same captured value can enqueue identical replacements and lose an increment. The following exercise is React 19 and TypeScript 5 source checked into this repository, not a remote code runner.

## Build the mental model

When multiple queued changes depend on earlier changes, pass updater functions rather than a captured count. A functional setter receives the previous queued state, including earlier updates. **Important boundary:** A pure-function test validates state transitions and static React rendering checks initial markup; neither alone simulates an interactive browser or verifies hydration and effect behavior.

**Predict before you run:** Two sequential functional updates increase any starting count by exactly two.
