## The problem we're solving

Three queued actions end with the last action only because earlier changes were overwritten. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React batches state updates in event handlers. Functional updaters are applied in queue order to the evolving previous value, not repeatedly to the same stale closure. This avoids losing updates during a single event.

**Predict before running:** The repaired implementation respects its documented contract.
