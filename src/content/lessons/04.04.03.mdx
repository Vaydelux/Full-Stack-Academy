## The problem we're solving

A module's data transformation mutates an imported settings object and loses type-only import clarity. This is a local repository/package-development lesson. A passing fixture alone is not a published npm release and does not create a Vercel deployment.

## Build the mental model

TypeScript supports import type to express compile-time-only dependencies. Runtime imports execute code and may have side effects; type-only imports are erased. Organize public and local imports predictably, and avoid mutating shared imported objects.

**Predict before running:** The imported Row contract is compile-only while sorting a clone leaves the caller's array untouched.
