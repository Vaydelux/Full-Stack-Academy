## The problem we're solving

A component test asserts implementation details but never checks whether the user can see its message. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React Testing Library encourages tests that query semantic DOM output instead of component internals. Test behavior from the user's perspective using screen and userEvent. This academy offline fixture currently verifies server-rendered HTML; it is not a substitute for browser-level RTL interaction tests.

**Predict before running:** The repaired implementation respects its documented contract.
