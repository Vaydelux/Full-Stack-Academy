## The problem we're solving

An application inherits a shared tsconfig but disables strict mode and quietly accepts an implicit-any parameter. This offline workshop is part of the Git/monorepo track; no workspace installation, external package query or Vercel build runs when reading the lesson.

## Build the mental model

A shared TypeScript preset reduces drift across packages, while each consumer extends the preset from a real path. Inherited compiler options can be overridden, so a security-sensitive strict baseline should be verified in actual effective configs. This lab models key overrides, while tsc --showConfig is the authoritative resolver.

**Predict before running:** Safe overrides preserve strict typing, but loosening strictness is explicitly rejected.
