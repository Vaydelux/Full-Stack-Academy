## The problem we're solving

A virtual list computes an end index beyond its dataset length and can render duplicate rows when scrolling near the bottom.

## Build the mental model

Virtualization renders a window of items based on scroll position, item heights and overscan. Clamp window indices, preserve stable item identity and provide an accessible alternative. Virtualization trades DOM size for measurement and focus complexity.

**Predict first:** The rendered interval is always within total item count and never exceeds the dataset.

```ts

export function solve(total:number,start:number,windowSize:number){if(!Number.isInteger(total)||total<0||!Number.isInteger(start)||start<0||!Number.isInteger(windowSize)||windowSize<1)throw new TypeError("Invalid virtual window");const first=Math.min(start,total);return {start:first,end:Math.min(total,first+windowSize)};}

```

**Why it works:** Virtualization renders a window of items based on scroll position, item heights and overscan. Clamp window indices, preserve stable item identity and provide an accessible alternative. Virtualization trades DOM size for measurement and focus complexity.

**Proof:** Run `npm run lab:ui-virtual-lists` and inspect the instructor test output.

</LessonStep>

## Production library pattern

```tsx
import {useVirtualizer} from "@tanstack/react-virtual";
// Inside a client component with a scrollElement ref:
const v=useVirtualizer({count:rows.length,getScrollElement:()=>scrollRef.current,estimateSize:()=>44,overscan:5});
```

Virtualizer integration needs a browser scroll container and measured layout. The offline solver only checks interval bounds.
