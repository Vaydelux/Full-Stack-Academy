## The problem we're solving

An optional numerical setting uses || and replaces a legitimate zero with the default. The checked-in examples are TypeScript 5 modules targeting the repository's strict compiler settings. Node 24 plus the installed tsx runner execute the instructor tests without a remote environment.

## Build the mental model

undefined usually means a missing value; null often means explicitly absent. ?? supplies the fallback only for null or undefined, preserving meaningful falsy values such as 0 and false. Optional properties may be missing entirely, which is distinct from an explicit undefined under exactOptionalPropertyTypes.

**Predict before running:** Zero remains zero, but truly nullish values receive a default.

Preserve exported `solve`; narrow unknown inputs and maintain the intended inferred/annotated return contract.

```ts
export function solve(value:number|null|undefined,fallback=10):number{if(!Number.isFinite(fallback))throw new TypeError('Finite fallback required');const selected=value??fallback;if(!Number.isFinite(selected))throw new TypeError('Finite selected value required');return selected;}
```

**Why it works:** undefined usually means a missing value; null often means explicitly absent. ?? supplies the fallback only for null or undefined, preserving meaningful falsy values such as 0 and false.
