## The problem we're solving

A local environment file holding a synthetic placeholder is accidentally added to the index alongside legitimate source files. This lesson is an offline, repeatable source-control exercise; it never touches the learner's actual project repository or opens a hosted pull request.

## Build the mental model

A .gitignore pattern prevents untracked files matching it from being added by broad staging. It does not stop tracking a file already committed or staged. Use git check-ignore and git ls-files to verify policies, and rotate real credentials immediately after exposure; never assume deleting a commit erases copies.

**Predict before running:** The local fake environment file remains untracked and is excluded by .gitignore.
