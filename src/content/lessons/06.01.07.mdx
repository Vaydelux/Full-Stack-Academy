## The problem we're solving

The decrement action increments the counter because both cases share the same state transition. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Handlers should be passed as functions, not invoked while rendering. Functional state setters read the latest committed queued value when computing next state.

**Predict before running:** The repaired implementation respects its documented contract.

export function solve(count:number,event:'up'|'down'):number{if(!Number.isInteger(count)||count<0)throw new TypeError('Valid counter required');return event==='up'?count+1:Math.max(0,count-1);}
