## The problem we're solving

An editorial site publishes an article with a meaningful title and description, but a draft must not be indexed.

**Defect:** The starter marks every page indexable, including unpublished drafts.

## Build the mental model

Generate unique, accurate page metadata and explicitly noindex unpublished or missing content.

**Predict before running:** Published article indexes with a descriptive title; draft metadata is noindex.

The academy exercises reviewed TypeScript/React logic locally. It does not automatically exercise the Next.js Metadata API, search crawler, browser page loading, network waterfall, Lighthouse or real-user field metrics. Those are separate qualification gates.

```tsx
export function articleMetadata(title:string,published:boolean){
 const safeTitle=title.trim()||'Untitled';
 return {title:safeTitle+' | Academy',description:'Read '+safeTitle+' on the academy.',robots:{index:published,follow:true}};
}
```

**Root principle:** Generate unique, accurate page metadata and explicitly noindex unpublished or missing content.

</LessonStep>

**Next.js 16 usage pattern (illustrative):**

```tsx
// app/articles/[slug]/page.tsx
import type {Metadata} from 'next';
export async function generateMetadata({params}:{params:Promise<{slug:string}>}):Promise<Metadata>{
 const {slug}=await params;
 const article=await findPublishedArticle(slug);
 if(!article)return {title:'Article not found',robots:{index:false}};
 return {title:article.title,description:article.summary,robots:{index:true}};
}
```

**Production nuance:** Next metadata has inheritance/overwrite behavior; nested object fields like openGraph and robots need deliberate merging. The helper tests the policy only, not actual HTML head injection.

</LessonStep>
