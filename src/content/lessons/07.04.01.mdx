## The problem we're solving

A lesson page produces an empty title and description despite having a clear public heading. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Metadata helps crawlers and people understand page intent. Provide unique, descriptive titles and summaries that match visible content. Never fabricate rankings; metadata does not substitute for clear semantics and accessible headings.

**Predict before running:** The repaired implementation respects its documented contract.
