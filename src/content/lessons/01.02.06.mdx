## The problem we're solving

A simple hint uses a custom modal that steals keyboard focus and never closes on Escape. Another piece of inline documentation behaves like a modal even though it should not interrupt the page.

## Build the mental model

Use details/summary for inline disclosures, the Popover API for transient non-modal hints, and dialog.showModal() for interactions requiring a modal with background inertness. Native controls provide important keyboard and focus behavior, but accessible names and sensible close actions still matter. A modal dialog needs a descriptive name, and focus should return to the opener. The showModal method requires JavaScript; declarative popover buttons and details can work without it. A popover is not a substitute for a real modal.

**Predict before running:** Does a native modal dialog make the rest of the page interactable while open? No: showModal makes the rest of the document inert to interaction.

<LessonStep number={2} title={"Create a non-modal help popover"} file="labs/forms-native-dialog/starter/index.html" expected={"The popover appears without locking access to the rest of the page."}>

The popovertarget button controls a lightweight in-page hint.

```html
<button type="button" popovertarget="help-popover">Show quick tip</button>
<div id="help-popover" popover="auto">Check the event schedule before arrival.</div>
```

</LessonStep>

<LessonStep number={3} title={"Open and close a real named modal"} file="labs/forms-native-dialog/starter/index.html" expected={"The dialog receives modal focus and closes through its native form or Escape."}>

Use showModal and a native method=dialog close form; Escape also requests dismissal.

```js
<button type="button" id="open-settings">Open settings</button>
<dialog id="settings-dialog" aria-labelledby="settings-heading">
  <h2 id="settings-heading">Workshop preferences</h2>
  <form method="dialog"><button type="submit">Close settings</button></form>
</dialog>
<script>document.querySelector('#open-settings').addEventListener('click',()=>document.querySelector('#settings-dialog').showModal());</script>
```

</LessonStep>
