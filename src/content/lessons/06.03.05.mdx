## The problem we're solving

An analytics button needs an internal event sequence number without rendering on every internal increment. The starter always returns one because it never advances the ref's current value. The goal is to learn the React runtime contract rather than memorize hook names.

## Build the mental model

Use a ref for an imperative value that should persist without itself triggering a render. When it must persist across renders but a change should not itself update the displayed UI. **Distinguish source-level correctness from runtime evidence:** Pure helpers can be tested without a browser, but an SSR output assertion cannot prove that an Effect ran, a ref focused an actual input or a global listener was removed after unmount.

**Predict before you run:** Three calls against one ref return 1, 2 and 3, and distinct refs remain independent.
