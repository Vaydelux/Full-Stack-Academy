## The problem we're solving

The starter includes internal secrets in its column list. Enterprise interfaces need correct data scope, stable identities, accessible states and predictable behavior under pagination, refresh and mobile layouts.

## Build the mental model

Define typed, allowlisted columns for only public fields and keep internal credentials out of the browser's table model.

**Prediction:** Only id, name, and status are visible columns; privateKey is excluded.

**Scope of evidence:** The instructor's local Node tests exercise a pure data transformation. TanStack Table v8 and TanStack Virtual require separate dependency installation and mounted browser tests. Never treat sorting the current server page as global sorting, or browser-side role checks as server authorization.
