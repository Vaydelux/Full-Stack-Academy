## The problem we're solving

A slow filter result is scheduled as an urgent update, making the controlled input feel unresponsive while heavy results render. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

useTransition marks some updates as non-blocking so urgent input stays responsive. A transition does not make expensive JavaScript disappear; measure UI latency and keep controlled text updates urgent. Framework Actions have ordering behavior to consider.

**Predict before running:** The repaired implementation respects its documented contract.
