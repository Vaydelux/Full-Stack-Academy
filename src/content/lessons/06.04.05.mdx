## The problem we're solving

A feedback list feels unresponsive while a comment is being saved, so the UI should show a pending entry without implying it has already been persisted. The starter replaces the original comment collection with one optimistic item, discarding existing comments.

## Build the mental model

Render a temporary optimistic entry during an Action while retaining authoritative committed state separately. It is temporary presentation state; a rejected operation needs reconciliation rather than pretending the backend accepted it. The React 19 APIs used here have distinct contracts: context passes values, transitions schedule nonurgent updates, deferred values let rendering lag, and optimistic state is a temporary view during an Action. These lessons use local data, not backend persistence.

**Predict before you run:** Existing entries remain in order and the new item has an explicit pending state until committed.

export function OptimisticComments({seed}:{seed:Comment[]}){
 const [saved,setSaved]=useState(seed);
 const [display,addPending]=useOptimistic(saved,optimisticAppend);
