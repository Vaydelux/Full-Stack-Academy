## The problem we're solving

A three-page public website is generated with broken path slugs and no reliable metadata or navigation. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A public App Router site needs stable route segments, semantic pages, persistent layout, accessible links and useful metadata. Validate route names and ownership; local pure helpers cannot substitute for a real Next build and browser navigation tests.

**Predict before running:** The repaired implementation respects its documented contract.
