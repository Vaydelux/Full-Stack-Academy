## The problem we're solving

A fictional product catalogue needs a public landing page, route-safe product detail pages and meaningful 404 behavior.

**Failure:** The starter accepts any product slug, returning a fabricated entry for unknown pages.

## Build the mental model

Combine routes, layout, dynamic params, metadata, not-found decisions and accessible navigation into one small public-site contract.

**Prediction:** Known slugs render validated catalogue information; unknown slugs are rejected and public links stay internal.

**Proof boundary:** The local Node/TSX fixture verifies this lesson's deterministic model and initial React markup. It does **not** start Next.js, compile route conventions, simulate streaming, or prove HTTP status codes. A separately built Next application and browser/HTTP test are needed before release qualification.

<LessonStep number={2} title="Implement the safe Next.js-oriented contract" file="labs/next-public-site-capstone/starter/solution.tsx" expected="Known slugs render validated catalogue information; unknown slugs are rejected and public links stay internal.">

```tsx
export type Product={slug:string;title:string};
export const products:readonly Product[]=[{slug:'starter-kit',title:'Starter kit'},{slug:'ui-handbook',title:'UI handbook'}];
export function findProduct(slug:string):Product|null{
 return products.find(product=>product.slug===slug)??null;
}
export function Catalogue(){return <ul>{products.map(product=><li key={product.slug}>{product.title}</li>)}</ul>;}
```
