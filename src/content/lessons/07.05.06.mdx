## The problem we're solving

An application is considered healthy because typechecking passed, even though its production server fails on a real route. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A release gate needs distinct checks for types, lint, production compilation, startup, navigation and runtime errors. A green build is necessary but not sufficient for browser functionality, permissions or accessibility. Track exact commit and environment without exposing secrets.

**Predict before running:** The repaired implementation respects its documented contract.
