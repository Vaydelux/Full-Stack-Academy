## The problem we're solving

Build and runtime diagnostics matters in a production-facing Next.js application. **Initial defect:** The starter reports every compiler, configuration and hydration error as a CSS issue.

## Build the mental model

Classify build errors at the correct boundary before changing code and record the exact commit, runtime and failing command. **Predict:** Type errors, missing env and hydration regressions receive separate classifications.

These source tests are not a replacement for real Next.js build, authentic requests, tenant-scoped database reads, observability or production deployment checks.
