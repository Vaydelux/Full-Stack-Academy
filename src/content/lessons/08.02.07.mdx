## The problem we're solving

The starter reports zero for every series regardless of the plotted values. Advanced UI interactions need a robust identity and focus model so the component works with touch, keyboard and screen readers rather than only a mouse.

## Build the mental model

Every chart needs a textual summary or data-table alternative, with honest handling of empty or invalid data. **Expected behavior:** The data summary reports the true count and total; invalid numeric points are rejected.

**Evidence boundary:** The local test checks a pure data or interaction-policy function. It does not prove DOM focus, ARIA announcements, actual event sequences, animation timing or a third-party library's mounted behavior. Use a real local browser and accessible component primitives for those claims.
