## The problem we're solving

A route exposes internal error messages instead of a safe fallback and never offers a retry action. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A loading.tsx boundary provides route-level pending UI, while an error.tsx Client Component can display a recoverable error and call reset. Error boundaries do not replace request-layer logging or authorization.

**Predict before running:** The repaired implementation respects its documented contract.
