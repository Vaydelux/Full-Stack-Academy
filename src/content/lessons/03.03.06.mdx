## The problem we're solving

A client retries a 404 response repeatedly and never stops after its maximum attempts. This lab uses local Node.js timers, Promises and injected mock transport rather than relying on external APIs or a deployed site.

## Build the mental model

Retries should be bounded and error-aware: transient 5xx or network failures may be retried, while most 4xx responses should fail immediately. Timeouts and cancellation are separate concerns; never retry an aborted request. Use injected transport to test policy without real network traffic.

**Predict before running:** Transient failures receive bounded retries, but a 404 stops after one request.

<LessonStep number={2} title="Apply the async boundary and handle errors" file="labs/js-retry/starter/solution.mjs" expected={"Transient failures receive bounded retries, but a 404 stops after one request."}>

Make the smallest meaningful correction and preserve the `solve` module contract. For transport cases, keep request functions injectable so the same test can simulate success, failure, timeout and cancellation.

```js
export async function solve(fetcher,{attempts=3,signal}={}){if(typeof fetcher!=='function'||!Number.isInteger(attempts)||attempts<1)throw new TypeError('Valid fetcher/attempts required');let last;for(let attempt=1;attempt<=attempts;attempt++){if(signal?.aborted)throw signal.reason??new Error('aborted');try{const response=await fetcher({attempt,signal});if(response.ok)return response.data;const error=new Error('HTTP '+response.status);if(response.status<500)throw Object.assign(error,{permanent:true});last=error;}catch(error){if(error.permanent||signal?.aborted)throw error;last=error;}}throw last;}
```

**Predict before running:** Transient failures receive bounded retries, but a 404 stops after one request.

**Why it works:** Retries should be bounded and error-aware: transient 5xx or network failures may be retried, while most 4xx responses should fail immediately. Timeouts and cancellation are separate concerns; never retry an aborted request. Use injected transport to test policy without real network traffic.

**Proof:** Verify that all promises settle and timer/listener cleanup occurs even after failure.

</LessonStep>
