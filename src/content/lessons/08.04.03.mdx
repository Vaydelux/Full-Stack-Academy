## The problem we're solving

An icon-only input lacks a label and its validation error is not programmatically associated with the field.

## Build the mental model

Labels identify what the user must enter; error messages should be connected through aria-describedby or accessible error conventions. Preserve native validation and input types, and explain a correction rather than only changing border color.

**Predict first:** A valid field has a meaningful associated label and detects whether an error description needs wiring.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-form-accessibility/starter/solution.ts" expected="A valid field has a meaningful associated label and detects whether an error description needs wiring.">

```ts

export type Field={id:string;label:string;error?:string};export function solve(field:Field){if(!field.id.trim()||!field.label.trim())throw new TypeError("Field ID and label required");return {id:field.id,labelled:true,described:Boolean(field.error?.trim())};}

```

**Why it works:** Labels identify what the user must enter; error messages should be connected through aria-describedby or accessible error conventions. Preserve native validation and input types, and explain a correction rather than only changing border color.

**Proof:** Run `npm run lab:ui-form-accessibility` and inspect the instructor test output.

</LessonStep>

```tsx
import React from "react";
export function Workshop(){return <form aria-label="Form accessibility workshop"><h2>Contact form</h2><label htmlFor="contact-email">Email address</label><input id="contact-email" type="email" aria-describedby="email-error" aria-invalid="true" required/><p id="email-error">Enter a valid email address.</p><button type="submit">Continue</button></form>;}

```

This sample uses semantic React without requiring an uninstalled UI package. Server rendering does not execute handlers or certify focus management.

**Proof:** The lab renders initial HTML with React DOM Server. A real browser check remains mandatory.
