## The problem we're solving

A route builder exposes an internal route-group folder in the public URL, generating invalid navigation links. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

In the Next.js App Router, folders define URL segments, while parenthesized route groups organize layouts without contributing to the URL. Page files make a segment publicly routable; private folders and parallel routes need distinct handling.

**Predict before running:** The repaired implementation respects its documented contract.
