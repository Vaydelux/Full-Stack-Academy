## The problem we're solving

A team passes an automated lint rule and adds a 'WCAG compliant' badge, without checking keyboard access, understandable feedback or actual user journeys.

## Build the mental model

WCAG 2.2 organizes accessibility under four principles: Perceivable, Operable, Understandable and Robust (POUR). Specific normative success criteria have testable requirements and conformance levels A, AA and AAA. A preliminary checklist helps identify gaps but does not establish conformance. An audit must consider the entire scoped page/process, technology support, and relevant criteria, with human review and assistive-tech testing where appropriate. This lab groups example questions by POUR and records only a **local self-assessment**.

**Predict before running:** Does checking four boxes prove a complex website meets every WCAG 2.2 AA criterion? No; it is not a conformance assessment.

## Prerequisites

Complete [the previous lesson](/learn/01.03.03). Work in a trusted local checkout with Node.js 24 and Chromium. Browser role and focus tests are valuable but are not substitutes for actual screen-reader use or formal accessibility conformance testing.

Use a legend and four labeled checkboxes; a checklist is a starting point, not a certification.

```html
<fieldset><legend>Preliminary page review</legend>
  <label><input type="checkbox" name="pour" value="perceivable"> Perceivable: text alternatives</label>
  <label><input type="checkbox" name="pour" value="operable"> Operable: keyboard actions</label>
  <label><input type="checkbox" name="pour" value="understandable"> Understandable: field instructions</label>
  <label><input type="checkbox" name="pour" value="robust"> Robust: native semantics</label>
</fieldset>
```

</LessonStep>

<LessonStep number={2} title={"Make the feedback scoped and honest"} file="labs/a11y-wcag/starter/index.html" expected={"The result reports a local count without claiming certification."}>

Count only the learner's checked observations without implying WCAG success.

```js
const chosen=document.querySelectorAll('input[name="pour"]:checked').length;
const total=document.querySelectorAll('input[name="pour"]').length;
document.querySelector('#result').textContent=chosen+' of '+total+' preliminary observations marked. Not a conformance audit.';
```

</LessonStep>
