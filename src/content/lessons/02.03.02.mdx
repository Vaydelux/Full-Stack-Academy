## The problem we're solving

A subtitle uses very pale text on white, making it unreadable despite a visually clean design. We will repair a specific CSS behavior in an offline component so that a future design system has predictable boundaries. There is no external font, image or API dependency.

## Build the mental model

Colors can be expressed in sRGB and perceptual spaces such as OKLCH; perceptual uniformity does not itself guarantee WCAG contrast. For ordinary text, the WCAG 2 contrast ratio target at AA is 4.5:1. Confirm computed foreground/background colors, alpha compositing and contrast rather than relying only on designer intuition.

**Predict before running:** The subtitle has visibly darker foreground text against the white background, and the accent uses OKLCH color syntax.

## Explore and verify

A syntactically valid color, selector or animation is not necessarily accessible or performant. Test color contrast for actual foreground/background pairs; preserve focus, reduced-motion behavior and narrow layouts. The Node fixture assertions check reviewed CSS patterns, and Chromium independently checks representative rendered behavior. Neither constitutes a full multi-device accessibility certification.
