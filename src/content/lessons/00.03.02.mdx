## The problem we're solving

A bug appears only in a 500-character input, and nobody knows which characters matter. Every attempted fix changes many things at once, so the team cannot tell which factor caused the failure.

## Build the mental model

A minimal reproducer removes unrelated state while preserving the observed failure. Start with an expected result, actual result, exact environment and failing input. Hold the failure predicate constant while reducing the case. A greedy one-character deletion pass is a useful beginner technique; it produces a locally minimal result, not necessarily the globally shortest possible input. Keep deterministic seeds, fixed versions and independent experiments. A regression test should fail before the repair and pass afterward.

**Predict before running:** If the bug is triggered only when a string contains BUG, which characters in 'helloBUGworld' are indispensable? B, U and G in that order.

<LessonStep number={2} title={"Remove irrelevant characters"} file="labs/minimal-repro/starter/exercise.mjs" expected={"minimizeRepro('helloBUGworld', fails) returns 'BUG'."}>

Start from a confirmed failing input and delete characters only if the bug still reproduces. Limit input size so the algorithm cannot consume unbounded time.

```js
export function minimizeRepro(input, fails) {
  if (typeof input !== 'string' || input.length > 2000 || !fails(input)) {
    throw new Error('Provide a bounded, failing string');
  }
  let current = input;
  for (let index = 0; index < current.length;) {
    const candidate = current.slice(0,index) + current.slice(index+1);
    if (fails(candidate)) current=candidate;
    else index++;
  }
  return current;
}
```

</LessonStep>

<LessonStep number={3} title={"Prove a minimal counterexample"} file="labs/minimal-repro/starter/exercise.mjs" expected={"The fixture proves the reduced case still fails and deleting any character stops this predicate."}>

Run the lab tests, then change the example to a second input. Record the smallest failing input and the expected fixed behavior as a new regression test.

```js
const minimal = minimizeRepro('helloBUGworld', s => s.includes('BUG'));
console.log(minimal); // BUG
// After the bug is fixed, test that the original input no longer triggers the bad outcome.
```

</LessonStep>

## Bug Hunt: identify and verify the repair

The reducer deletes characters without checking whether the failure still occurs. The result looks small but no longer fails. Restore the predicate check after each candidate deletion, then add a regression assertion.
