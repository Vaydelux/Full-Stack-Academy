## The problem we're solving

Web and API packages duplicate the request model, so schema drift produces incompatible client and server behavior. This offline workshop is part of the Git/monorepo track; no workspace installation, external package query or Vercel build runs when reading the lesson.

## Build the mental model

A shared contracts package centralizes public transport types and runtime parsing. The API must validate unknown input, while the web package imports the shared type rather than re-declaring it. pnpm workspace and turbo task configs describe build intent; local tests compile the actual three-package TS source, while package installation/publishing/deployment remain separate gates.

**Predict before running:** Both web and API consume the same checked-in shared model, and malformed data never reaches the domain.
