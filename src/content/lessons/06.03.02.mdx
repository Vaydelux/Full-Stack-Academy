## The problem we're solving

A subscription stays connected to an old room when the room ID changes because the effect ignores its dependency. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Effects synchronize React's committed state with external systems, not calculate render-only values. Subscribe using current dependencies and return cleanup to disconnect the old resource before reconnecting.

**Predict before running:** The repaired implementation respects its documented contract.
