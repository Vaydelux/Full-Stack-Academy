## The problem we're solving

A cached catalog is impossible to invalidate surgically because it has no meaningful tag. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

With Cache Components enabled, use cache declares an explicit cached scope, cacheLife sets a lifetime and cacheTag attaches domain tags. Avoid user-specific data in global cache keys and choose stable, bounded tags that map to real mutations.

**Predict before running:** The repaired implementation respects its documented contract.
