## The problem we're solving

A library emits JavaScript but neglects declaration output, leaving downstream TypeScript consumers with no documented public contract. This is a local repository/package-development lesson. A passing fixture alone is not a published npm release and does not create a Vercel deployment.

## Build the mental model

Declaration files describe the exported API at compile time. tsc can emit .d.ts using declaration plus emitDeclarationOnly; avoid exposing internal types and ensure declaration paths match package exports. The compiler test should inspect actual emitted declarations rather than simply searching a handwritten file.

**Predict before running:** The exported typed function returns a numeric result and a generated .d.ts exposes PublicPoint and solve.
