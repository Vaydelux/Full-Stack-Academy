## The problem we're solving

Repeated keyboard shortcut presses start duplicate intervals and never release them, causing the timer to speed up. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A reliable timer uses at most one active interval, cleans it on unmount, and ignores repeated activation. Keyboard listeners should be removed in cleanup and should not intercept typing inside form fields.

**Predict before running:** The repaired implementation respects its documented contract.

```tsx
import React,{useEffect,useReducer} from 'react';
import {solve} from './solution';
export function Workshop(){const [state,dispatch]=useReducer(solve,{running:false,seconds:0});useEffect(()=>{if(!state.running)return;const id=setInterval(()=>dispatch('tick'),1000);return()=>clearInterval(id);},[state.running]);useEffect(()=>{const listener=(e:KeyboardEvent)=>{if((e.target as HTMLElement|null)?.closest('input,textarea,[contenteditable]'))return;if(e.code==='Space'){e.preventDefault();dispatch(state.running?'stop':'start');}};window.addEventListener('keydown',listener);return()=>window.removeEventListener('keydown',listener);},[state.running]);return <section aria-label="Timer lab"><h2>Reliable timer</h2><button type="button" onClick={()=>dispatch(state.running?'stop':'start')}>{state.running?'Stop':'Start'}</button><output>{state.seconds}s</output></section>;}

```
