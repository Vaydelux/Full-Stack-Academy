## The problem we're solving

A counter widget should use React state, rather than assigning a mutable variable during rendering. A nonreactive local variable or a constant initial label never causes React to render the updated count. The following exercise is React 19 and TypeScript 5 source checked into this repository, not a remote code runner.

## Build the mental model

State is a snapshot for each render, so an event handler sees values captured by that render. It captures the state snapshot from the render that created that handler. **Important boundary:** A pure-function test validates state transitions and static React rendering checks initial markup; neither alone simulates an interactive browser or verifies hydration and effect behavior.

**Predict before you run:** A counter reflects its initial state and a functional increment computes from the supplied prior value.

```tsx
import {useState} from 'react';
export function increment(previous:number){return previous+1;}
export function SnapshotCounter({initial=0}:{initial?:number}) {
 const [count,setCount]=useState(initial);
 return <button type="button" onClick={()=>setCount(increment)}>Count: {count}</button>;
}
```
