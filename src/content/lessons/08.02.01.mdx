## The problem we're solving

A card animation plays an aggressive 600ms slide for every user, including people who requested reduced motion.

## Build the mental model

Use motion deliberately to reinforce hierarchy and state. Honor prefers-reduced-motion by eliminating nonessential transforms or providing an instant state change. Don't assume duration alone guarantees accessible or efficient animation.

**Predict first:** When reduced motion is requested, nonessential transforms turn off instead of simply running faster.

## Production library pattern

```tsx
"use client";
import {motion,useReducedMotion} from "motion/react";
function Panel(){const reduce=useReducedMotion();return <motion.section initial={false} animate={{opacity:1,x:reduce?0:12}} transition={{duration:reduce?0:0.18}}>Details</motion.section>;}
```

Motion package integration and animations need a real browser and reduced-motion media-query tests; SSR markup alone cannot certify interaction animation.
