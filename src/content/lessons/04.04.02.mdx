## The problem we're solving

A helper labels every .js and .cjs file as ESM, producing incorrect runtime module expectations. This is a local repository/package-development lesson. A passing fixture alone is not a published npm release and does not create a Vercel deployment.

## Build the mental model

Node.js treats .mjs as ESM and .cjs as CommonJS. A .js file is interpreted according to the nearest package.json type and Node's module detection behavior. A small classifier can model explicit extensions, but a real resolver must also inspect package scope and exports.

**Predict before running:** Explicit .mjs and .cjs extensions retain their runtime meaning; .js follows the package scope.
