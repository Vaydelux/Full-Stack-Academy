## The problem we're solving

The page uses clickable divs with pointer events, a hidden focus indicator and a long navigation area. Keyboard users cannot predict which element will activate or reach the article efficiently.

## Build the mental model

Links navigate; buttons perform actions. Native HTML exposes these roles and implements Enter and Space activation appropriately. Tabbing should follow meaningful DOM order, not a visual-only arrangement created with positive tabindex. A skip link must target an actual content element; a focusable target helps a keyboard user continue at the right point. Use CSS focus-visible to create a strong focus indicator and never remove outlines without an equivalent replacement. Use a pointer for optional convenience, not as the sole input method.

**Predict before running:** A div styled as a button does not automatically receive focus or activate through Enter/Space. A native button does.

<LessonStep number={1} title={"Make the skip link the first keyboard target"} file="labs/a11y-keyboard/starter/index.html" expected={"Tab reaches the skip link before the navigation."}>

Place the link before the navigation and point it at main.

```html
<a class="skip" href="#main-content">Skip to main content</a>
<header><p>Workshop guide</p></header>
<nav aria-label="Page navigation"><a href="#resources">Resources</a></nav>
```

</LessonStep>

<LessonStep number={2} title={"Write native actions and visible focus styles"} file="labs/a11y-keyboard/starter/index.html" expected={"Tab and Enter or Space activate the native button."}>

Use a button rather than an interactive div; keep focus visible.

```html
<main id="main-content" tabindex="-1">
  <h1>Keyboard learning tour</h1>
  <button type="button" id="reveal-tip">Show keyboard tip</button>
</main>
<style>button:focus-visible,a:focus-visible{outline:3px solid #d76300;outline-offset:4px}</style>
```

</LessonStep>

<LessonStep number={3} title={"Use an accessible status, not an alert popup"} file="labs/a11y-keyboard/starter/index.html" expected={"The tip appears in a polite live region and works when the button is activated by keyboard."}>

Display the result of the optional tip action without claiming form submission.

```js
document.querySelector('#reveal-tip').addEventListener('click',()=>{
  document.querySelector('#tip').textContent='Tip: use Tab to move and Shift+Tab to go back.';
});
```

</LessonStep>
