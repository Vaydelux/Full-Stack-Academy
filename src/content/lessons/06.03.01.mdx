## The problem we're solving

A team roster badge changes labels unpredictably because a module-level counter is incremented whenever React renders it. The starter returns a constant instead of calculating the member label from the current input. The goal is to learn the React runtime contract rather than memorize hook names.

## Build the mental model

Keep render-time calculations deterministic and free of observable mutations. It computes a value from current props and state without mutating external data or performing side effects. **Distinguish source-level correctness from runtime evidence:** Pure helpers can be tested without a browser, but an SSR output assertion cannot prove that an Effect ran, a ref focused an actual input or a global listener was removed after unmount.

**Predict before you run:** A single member renders a singular label; multiple members render plural; negative counts are rejected.

Make the smallest correction that addresses the causal defect while keeping the fixture's exported API stable:

```tsx
export function memberLabel(count:number):string {
  if(!Number.isSafeInteger(count)||count<0) throw new RangeError('Invalid count');
  return count===1 ? '1 member' : `${count} members`;
}
export function MemberSummary({count}:{count:number}) {return <p>{memberLabel(count)}</p>;}
```

**Why it works:** Keep render-time calculations deterministic and free of observable mutations.
