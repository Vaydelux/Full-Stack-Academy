## The problem we're solving

A rendering helper sorts a shared input array in place, so sibling components see their props mutate unexpectedly. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Render should be a pure calculation based on props and state. Sort a copy rather than mutating shared input. React can invoke rendering more than once in development Strict Mode and may abandon render work.

**Predict before running:** The repaired implementation respects its documented contract.
