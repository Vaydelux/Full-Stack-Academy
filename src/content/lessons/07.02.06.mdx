## The problem we're solving

An entire dashboard waits for a slow widget even when its navigation and other content could render immediately. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Suspense boundaries let ready content stream while slower server components suspend. Use meaningful fallback UI and avoid unnecessary waterfalls by starting independent data loads concurrently when appropriate.

**Predict before running:** The repaired implementation respects its documented contract.
