## The problem we're solving

A route returns one user's private report from a path-only shared cache when a different user visits the same URL. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Authorization and private cache partitioning must be enforced server-side for every data access. Prevent shared caching of private responses and send no-store headers; avoid leaking raw session identifiers. A toy key function is not sufficient to certify authentication.

**Predict before running:** The repaired implementation respects its documented contract.
