## The problem we're solving

Bug Hunt auth cache leak matters in a production-facing Next.js application. **Initial defect:** The starter allows any logged-in tenant to read another tenant's private record and labels it globally cacheable.

## Build the mental model

Authorize each tenant-scoped read and never globally share a cached private payload. Test cross-tenant denial with negative requests. **Predict:** Own-tenant private read is request-scoped; cross-tenant and anonymous access are denied; public content may be shared.

These source tests are not a replacement for real Next.js build, authentic requests, tenant-scoped database reads, observability or production deployment checks.

```tsx
export type Principal={userId:string;tenantId:string}|null;export type Resource={tenantId:string;visibility:'public'|'private'};export function readDecision(actor:Principal,resource:Resource){if(resource.visibility==='public')return {allowed:true,cache:'shared'};return {allowed:Boolean(actor&&actor.tenantId===resource.tenantId),cache:'request'};}
```

**Principle:** Authorize each tenant-scoped read and never globally share a cached private payload. Test cross-tenant denial with negative requests.
