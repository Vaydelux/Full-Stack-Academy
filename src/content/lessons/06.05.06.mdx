## The problem we're solving

A filtered list is unnecessarily recalculated during unrelated state updates, yet a memoization attempt closes over a stale query. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

useMemo caches a calculated value and useCallback caches a function identity between renders, subject to dependencies. Profile first and include every reactive dependency; both are performance hints, not correctness guarantees.

**Predict before running:** The repaired implementation respects its documented contract.
