## The problem we're solving

A selection resets when a list is filtered because the application tracks a row position rather than the row's stable identity. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React preserves state for the same component type and position, unless keys or tree placement identify a different instance. Track selected records by stable ID and intentionally change a key when a reset is desired.

**Predict before running:** The repaired implementation respects its documented contract.
