## The problem we're solving

A stock update mutates a nested location object and changes the original snapshot held by another UI component. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

Object spread is shallow. To update a nested object without affecting previous snapshots, copy each layer along the updated path. Validate the requested change and avoid treating Object.freeze on the top level as deep immutability.

**Predict before running:** The update returns a fresh location map and never modifies the previous stock snapshot.

```js
export function solve(stock,warehouse,delta){if(!stock||typeof stock.locations!=='object'||typeof warehouse!=='string'||!warehouse||!Number.isInteger(delta))throw new TypeError('Invalid adjustment');const current=stock.locations[warehouse]??0;const next=current+delta;if(next<0)throw new RangeError('Negative stock');return {...stock,locations:{...stock.locations,[warehouse]:next}};}
```
