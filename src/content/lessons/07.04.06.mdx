## The problem we're solving

A report declares a page fast based only on backend response latency, ignoring LCP, INP and CLS measured in the browser. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Core Web Vitals combine loading responsiveness and visual stability. Use field data over representative users and apply official thresholds: LCP at most 2.5 seconds, INP at most 200 milliseconds, CLS at most 0.1 for good experiences. Lab values are synthetic only.

**Predict before running:** The repaired implementation respects its documented contract.
