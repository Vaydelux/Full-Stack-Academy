## The problem we're solving

A workspace selector accidentally includes ordinary folders and misses one of the actual packages. This offline workshop is part of the Git/monorepo track; no workspace installation, external package query or Vercel build runs when reading the lesson.

## Build the mental model

pnpm-workspace.yaml specifies package globs that identify workspace package manifests. A workspace is a dependency installation and linking boundary, not simply every folder under apps. This lab checks an intentionally small explicit convention for apps/* and packages/*; the real pnpm resolver supports broader glob rules and exclusions.

**Predict before running:** Only direct apps/* and packages/* package manifests become workspace members.
