## The problem we're solving

A CSV export writes untrusted cell data beginning with = as formula content, which spreadsheet applications may execute when opened.

## Build the mental model

Spreadsheet CSV injection is a real export boundary. Preserve CSV quoting and escape potential formula prefixes with a safe leading apostrophe when targeting spreadsheet tools. Pair exports with clear filenames, filters and a print-only layout that doesn't leak private columns.

**Predict first:** CSV values that start with formula markers become inert text while quotes and commas remain correctly escaped.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-export-print/starter/solution.ts" expected="CSV values that start with formula markers become inert text while quotes and commas remain correctly escaped.">

```ts

export function solve(value:string):string{const safe=/^[\s]*[=+@-]/.test(value)?"'"+value:value;return `"${safe.replace(/"/g,'""')}"`;}

```

**Why it works:** Spreadsheet CSV injection is a real export boundary. Preserve CSV quoting and escape potential formula prefixes with a safe leading apostrophe when targeting spreadsheet tools. Pair exports with clear filenames, filters and a print-only layout that doesn't leak private columns.

**Proof:** Run `npm run lab:ui-export-print` and inspect the instructor test output.

</LessonStep>
