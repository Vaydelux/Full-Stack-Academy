## The problem we're solving

The starter emits raw values, allowing commas, quotes and formula prefixes to break cells or inject spreadsheet expressions. Enterprise interfaces need correct data scope, stable identities, accessible states and predictable behavior under pagination, refresh and mobile layouts.

## Build the mental model

Escape spreadsheet CSV quotes/newlines and neutralize formula-like user text; never export fields a user is not authorized to access.

**Prediction:** CSV values are quoted when necessary and formula-like text is prefixed with a neutralizing apostrophe.

**Scope of evidence:** The instructor's local Node tests exercise a pure data transformation. TanStack Table v8 and TanStack Virtual require separate dependency installation and mounted browser tests. Never treat sorting the current server page as global sorting, or browser-side role checks as server authorization.

```tsx
export function csvCell(value:string){const safe=/^[\s]*[=+\-@\t\r]/.test(value)?"'"+value:value;return /[",\r\n]/.test(safe)?'"'+safe.replace(/"/g,'""')+'"':safe;}
```

**Why this works:** Escape spreadsheet CSV quotes/newlines and neutralize formula-like user text; never export fields a user is not authorized to access.

</LessonStep>
