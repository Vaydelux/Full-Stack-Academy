## The problem we're solving

An optimistic comment is duplicated after confirmation and remains visible when a simulated validation failure occurs. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Optimistic state should have stable IDs and a transition lifecycle. Reconcile with authoritative success output, ignore duplicates and restore the previous confirmed list on rejection; never claim success based on a local button animation.

**Predict before running:** The repaired implementation respects its documented contract.
