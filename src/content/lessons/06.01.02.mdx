## The problem we're solving

A profile badge ignores its role prop, so different users render indistinguishably. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React components receive read-only props; their output should reflect the provided public input, not hidden mutable globals. Validate required public fields before presentation.

**Predict before running:** The repaired implementation respects its documented contract.
