## The problem we're solving

A static article page is unnecessarily marked use client, shipping all of its data-fetching logic and dependencies to the browser. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

App Router pages and layouts are Server Components by default. Add a Client Component boundary only where state, events, browser APIs or specific client libraries are required. Server-only code and credentials must never cross into a client import graph.

**Predict before running:** The repaired implementation respects its documented contract.
