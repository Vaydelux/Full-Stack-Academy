## The problem we're solving

A JSON-LD script embeds unescaped untrusted text that can close the script element in the rendered HTML. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Schema.org structured data must reflect real visible content. When inserting JSON-LD through a script, serialize safe objects and escape less-than signs so user-controlled text cannot inject HTML. Do not pass raw unsanitized JSON fragments.

**Predict before running:** The repaired implementation respects its documented contract.
