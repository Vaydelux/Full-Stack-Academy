## The problem we're solving

A task importer trusts an unknown payload and converts negative estimates into valid tasks. The checked-in examples are TypeScript 5 modules targeting the repository's strict compiler settings. Node 24 plus the installed tsx runner execute the instructor tests without a remote environment.

## Build the mental model

A typed domain model is a useful compile-time contract, but external payloads must be checked as unknown before building the model. Use a small discriminated status union, explicit ID validation, and typed immutable output so invalid input never becomes a valid Task by assertion.

**Predict before running:** Only complete, validated tasks enter the domain model and the returned record is frozen.

<LessonStep number={2} title="Implement the typed repair" file="labs/ts-task-model/starter/solution.ts" expected={"Only complete, validated tasks enter the domain model and the returned record is frozen."}>

Preserve exported `solve`; narrow unknown inputs and maintain the intended inferred/annotated return contract.

```ts
export type Task=Readonly<{id:string;title:string;minutes:number;status:'todo'|'done'}>;export function solve(raw:unknown):Task|null{if(!raw||typeof raw!=='object'||!('id' in raw)||typeof raw.id!=='string'||!raw.id.trim()||!('title' in raw)||typeof raw.title!=='string'||!raw.title.trim()||!('minutes' in raw)||typeof raw.minutes!=='number'||!Number.isInteger(raw.minutes)||raw.minutes<0||!('status' in raw)||(raw.status!=='todo'&&raw.status!=='done'))return null;return Object.freeze({id:raw.id.trim(),title:raw.title.trim(),minutes:raw.minutes,status:raw.status});}
```

**Predict before running:** Only complete, validated tasks enter the domain model and the returned record is frozen.

**Why it works:** A typed domain model is a useful compile-time contract, but external payloads must be checked as unknown before building the model. Use a small discriminated status union, explicit ID validation, and typed immutable output so invalid input never becomes a valid Task by assertion.

**Proof:** Compare the repaired student's output with the instructor solution under the same typed test cases.

</LessonStep>

assert.deepEqual(solve({id:'t1',title:'Plan',minutes:30,status:'todo'}),{id:'t1',title:'Plan',minutes:30,status:'todo'});assert.equal(solve({id:'t2',title:'Bad',minutes:-1,status:'todo'}),null);assert.equal(solve({id:'t3',title:'Bad',minutes:3,status:'unknown'}),null);assert.equal(solve(null),null);

**Predict before running:** Correct runtime behavior and a valid static type signature are separate, both required.

**Why it matters:** TypeScript cannot block malformed JSON after the source has been compiled; user input still needs runtime guards.
