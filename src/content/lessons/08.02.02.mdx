## The problem we're solving

A confirm dialog can be visually closed but leaves focus trapped on an invisible button and does not restore the trigger focus.

## Build the mental model

A modal must have a discernible title, modal semantics, keyboard dismissal strategy and predictable focus placement/return. Use a tested dialog primitive when possible; aria-modal alone does not implement focus trapping or background inertness.

**Predict first:** Closing the dialog is accompanied by a focus-return intention, and the visible dialog always has a name.

## Production library pattern

```tsx
"use client";
import * as Dialog from "@radix-ui/react-dialog";
function Confirm(){return <Dialog.Root><Dialog.Trigger>Delete</Dialog.Trigger><Dialog.Portal><Dialog.Overlay/><Dialog.Content><Dialog.Title>Delete draft?</Dialog.Title><Dialog.Description>Review before deleting.</Dialog.Description><Dialog.Close>Cancel</Dialog.Close></Dialog.Content></Dialog.Portal></Dialog.Root>;}
```

The Radix snippet is a library option, not a tested dependency in this course fixture. Proper modal focus is only certifiable in a running browser.
