## The problem we're solving

A v3-only stylesheet incorrectly qualifies as v4. A robust component system has to work across dark and light themes, keyboard input, small screens and real data, not merely appear correct in a screenshot.

## Build the mental model

Use CSS-first @import and @tailwindcss/postcss, rather than legacy v3-only entrypoints. **Predict before executing:** A v4 import passes; legacy-only directives fail.

**Runtime boundary:** This lesson's fixture is local TypeScript only. It does not compile Tailwind CSS, install shadcn or Radix/Base UI, mount a browser interaction, or verify visual contrast on real content. Those require a dedicated UI build and accessibility checks.
