## The problem we're solving

A tutorial uses an image with no alternate text or dimensions. On slow connections it can shift the layout, and readers who cannot see the diagram lose the instructional context.

## Build the mental model

Meaningful images need an alt description conveying what matters in context, not a generic 'image' label. Decorative images can use empty alt text so screen readers skip them. Width and height establish an intrinsic aspect ratio and reduce unexpected layout movement. `srcset` and `sizes` help the browser select image resources; `picture` with `source` allows art direction. `loading=lazy` is useful for below-the-fold images, but avoid lazily loading critical hero content when it hurts perceived speed. SVG assets here are simple, original local illustrations with no external requests or tracking.

**Predict before running:** Should a purely decorative flourish repeat the entire paragraph in alt text? No. Use `alt=''` for decoration when the adjacent text already conveys the meaning.

<LessonStep number={1} title={"Add a meaningful figure image"} file="labs/html-images/starter/index.html" expected={"The figure has a meaningful description and reserves a 16:9 ratio."}>

Use a local SVG diagram; describe the arrangement shown, not merely the format.

```html
<figure>
  <img src="assets/responsive-small.svg" width="640" height="360" alt="Workshop layout with a teaching area on the left and notes on the right">
  <figcaption>Example: two areas support different learning activities.</figcaption>
</figure>
```

</LessonStep>

<LessonStep number={2} title={"Offer responsive sources"} file="labs/html-images/starter/index.html" expected={"The fallback image works without source selection, and responsive resources remain local."}>

Provide art-directed wide media and a fallback source; browsers choose based on viewport and capabilities.

```html
<picture>
  <source media="(min-width: 48rem)" srcset="assets/responsive-wide.svg" type="image/svg+xml">
  <img src="assets/responsive-small.svg" srcset="assets/responsive-small.svg 640w, assets/responsive-wide.svg 960w" sizes="(max-width: 48rem) 100vw, 640px" width="640" height="360" alt="Workshop layout with a teaching area on the left and notes on the right" loading="lazy" decoding="async">
</picture>
```

</LessonStep>

<LessonStep number={3} title={"Keep decorative images separate from content"} file="labs/html-images/starter/index.html" expected={"The decorative image is ignored by accessible image listings."}>

A decorative accent does not need spoken detail; retain explicit dimensions.

```html
<img src="assets/responsive-small.svg" width="64" height="36" alt="" aria-hidden="true">
```

</LessonStep>
