## The problem we're solving

A package works in your Node CLI but fails when bundled for a browser because it imports node:fs. Another example tries to access document during server rendering. Both use JavaScript, but not the same host APIs.

## Build the mental model

The JavaScript language is specified by ECMAScript. Engines execute it; hosts expose additional APIs. Node uses V8 and provides process, filesystem, TCP and module loading APIs. Browsers expose the DOM and storage, and modern Node also has Fetch, URL and other web-standard APIs. A shared API does not make the environments identical. Use Node 24 LTS for the academy baseline and inspect the actual patch version. The .mjs extension declares an ES module; .cjs declares CommonJS; package.json type controls .js interpretation. ESM uses import/export; CJS uses require/module.exports.

<LessonStep number={3} title={"Build a runtime capability probe"} file="labs/node-runtime/starter/exercise.mjs" expected={"The probe can be tested with synthetic browser, Node and unknown hosts."}>

Provide an optional host object so unit tests need neither a real browser nor global overrides. Check capabilities individually; a hybrid host may expose both.

```js
export function inspectRuntime(host=globalThis) {
  const version=host.process?.versions?.node;
  return { node:typeof version==='string', dom:typeof host.document?.createElement==='function', fetch:typeof host.fetch==='function', nodeVersion:typeof version==='string'?version:null };
}
```

</LessonStep>

## Explore it yourself

Check node --version and then use node -p process.execPath. If the installed major differs from 24, use a trusted installer or version manager. Pin a major in project configuration and document the exact version tested. Never run a random downloaded install script merely because a tutorial lists it.

## Bug Hunt: diagnose before you change code

A React component imports a filesystem helper that is intended only for server use. Move that operation to a trusted server module and call an authorized API; pass only the permitted result to the browser.
