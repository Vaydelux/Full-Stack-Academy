## The problem we're solving

A global title selector changes headings in unrelated components, causing a surprising regression. We will repair a specific CSS behavior in an offline component so that a future design system has predictable boundaries. There is no external font, image or API dependency.

## Build the mental model

An explicit component namespace reduces accidental style leakage, but a data attribute is only a naming convention, not isolation. CSS Modules generate scoped class names at build time; Shadow DOM adds a stronger style boundary with separate tradeoffs. Here a local data-component selector demonstrates the naming discipline.

**Predict before running:** The course and article titles receive different colors despite sharing the item-title class.

## Explore and verify

A syntactically valid color, selector or animation is not necessarily accessible or performant. Test color contrast for actual foreground/background pairs; preserve focus, reduced-motion behavior and narrow layouts. The Node fixture assertions check reviewed CSS patterns, and Chromium independently checks representative rendered behavior. Neither constitutes a full multi-device accessibility certification.
