## The problem we're solving

Two independent state stores share the same backing array; one user's action appears in the other store. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

A factory should create isolated mutable state per instance and return fresh snapshots. Sharing a module-level array is a hidden global dependency; copying only the returned reference still permits later mutation unless copies are made at boundaries.

**Predict before running:** Each store is isolated and readers receive snapshots that cannot mutate private state.
