## The problem we're solving

An extracted method loses its original receiver and fails when invoked as a callback. The practice fixture uses Node 24 ESM and synthetic data, not an external service or browser deployment.

## Build the mental model

An ordinary function's this depends on its call site; extracting obj.method as a bare function loses the base object. bind creates a function with a fixed receiver, while arrow functions use lexical this. Prefer explicit parameters where context can be passed without implicit binding.

**Predict before running:** The detached callback still reads the reporter's prefix because the receiver was bound.
