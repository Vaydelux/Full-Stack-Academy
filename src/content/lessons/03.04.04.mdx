## The problem we're solving

A filter selection changes the UI but is lost on refresh because it is not represented in the URL. Browser Interaction topics require both executable JavaScript logic and a real local HTML document. The fixture uses synthetic content with no external scripts, endpoints or data uploads.

## Build the mental model

URL state makes a view reproducible and shareable. URLSearchParams handles encoding, and history.replaceState can update a fragment on the current document without navigation. A static file demo uses hash state to avoid file-origin restrictions; production apps should also handle back/forward popstate.

**Predict before running:** Applying CSS & Web creates an encoded #filter= fragment and displays the selected filter.

<LessonStep number={2} title="Implement the browser-safe interaction" file="labs/js-history/starter/index.html" expected={"Applying CSS & Web creates an encoded #filter= fragment and displays the selected filter."}>

Replace the defective handler without discarding native elements or semantics. For untrusted content use `textContent`, not an unsafe HTML sink.

```js
const output=document.querySelector('#status');const apply=()=>{const value=document.querySelector('#filter').value.trim();history.replaceState(null,'','#filter='+encodeURIComponent(value));output.textContent='Filter: '+value;};document.querySelector('#apply').addEventListener('click',apply);window.addEventListener('hashchange',()=>{const raw=location.hash.slice('#filter='.length);output.textContent='Filter: '+decodeURIComponent(raw);});
```

**Predict before running:** Applying CSS & Web creates an encoded #filter= fragment and displays the selected filter.

**Why the repair works:** URL state makes a view reproducible and shareable. URLSearchParams handles encoding, and history.replaceState can update a fragment on the current document without navigation. A static file demo uses hash state to avoid file-origin restrictions; production apps should also handle back/forward popstate.

**Proof:** Compare the resulting DOM and accessibility state to the instructor `solution/index.html` using the same input.

</LessonStep>
