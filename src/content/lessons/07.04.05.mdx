## The problem we're solving

A hero image lacks dimensions and a meaningful alt, causing layout shifts and accessibility problems. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Intrinsic image sizing and appropriate responsive sizes reduce unexpected layout movement; prioritize the actual LCP image based on measured evidence. Local fonts avoid network variability, but fonts and images still need representative loading tests.

**Predict before running:** The repaired implementation respects its documented contract.
