## The problem we're solving

Every article shares the generic homepage title because its route never defines specific metadata. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

The Next.js Metadata API can describe titles, descriptions, canonical links and social previews per route. Static exports are suitable for fixed pages; generateMetadata supports async route-specific values. Icons are supplied with file conventions or metadata definitions.

**Predict before running:** The repaired implementation respects its documented contract.
