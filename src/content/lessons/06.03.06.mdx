## The problem we're solving

A search form's Focus input button should focus its corresponding input without reaching into global DOM selectors. The starter never calls the input element's focus method. The goal is to learn the React runtime contract rather than memorize hook names.

## Build the mental model

Move focus through an intentional DOM ref only after the user activates a control. Imperative operations such as focus, measurement or integrating an external non-React widget. **Distinguish source-level correctness from runtime evidence:** Pure helpers can be tested without a browser, but an SSR output assertion cannot prove that an Effect ran, a ref focused an actual input or a global listener was removed after unmount.

**Predict before you run:** A mounted ref is focused exactly once and a missing ref is handled safely.

import {useRef} from 'react';
export function focusNode(node:Pick<HTMLInputElement,'focus'>|null):boolean {
 if(!node)return false;node.focus();return true;
}
export function FocusSearch() {
 const input=useRef<HTMLInputElement>(null);
 return <form onSubmit={e=>e.preventDefault()}><label htmlFor="focus-search">Search</label>
 <input id="focus-search" ref={input}/><button type="button" onClick={()=>focusNode(input.current)}>Focus input</button></form>;
}
