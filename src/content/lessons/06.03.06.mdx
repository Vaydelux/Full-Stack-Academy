## The problem we're solving

A focus helper attempts to focus a nonexistent input and throws after conditional rendering removes it. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

DOM refs are populated after the element commits; use an Effect or an event handler and check ref.current before focusing. Preserve native input semantics and a visible keyboard focus indication.

**Predict before running:** The repaired implementation respects its documented contract.
