## The problem we're solving

A developer wraps every component in memo without inspecting prop identity or whether rerenders are costly. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

React.memo can skip re-render when props are shallowly unchanged, but it is a performance optimization, not a semantic guarantee. Stable props and expensive rendering are prerequisites to meaningful benefit; rendering must still be correct without memo.

**Predict before running:** The repaired implementation respects its documented contract.
