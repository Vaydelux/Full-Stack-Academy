## The problem we're solving

A request displays Ready after an error because only the loading state has an explicit condition. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Loading, ready and error are distinct semantic states. Model every branch explicitly and provide accessible feedback without presenting old success data as fresh.

**Predict before running:** The repaired implementation respects its documented contract.

