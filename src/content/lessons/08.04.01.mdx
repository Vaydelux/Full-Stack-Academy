## The problem we're solving

The starter produces non-grid spacing for the same component role. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Define an intentional spacing rhythm and semantic heading hierarchy instead of multiplying arbitrary pixel offsets.

**Expected outcome:** An index into a 4px-based scale returns consistent predictable spacing.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
