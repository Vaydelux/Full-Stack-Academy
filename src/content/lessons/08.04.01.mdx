## The problem we're solving

A page uses arbitrary spacing sizes on adjacent cards so its visual hierarchy feels inconsistent and cannot be updated centrally.

## Build the mental model

Use a small, intentional spacing scale that reflects grouping and hierarchy rather than per-component magic numbers. Start with readable headings and structural grouping, then apply systematic rhythm and responsive density.

**Predict first:** Off-scale spacing values round to a consistent design grid and invalid values fail explicitly.

```ts
export function solve(spacing:number):number{if(!Number.isFinite(spacing)||spacing<0)throw new TypeError("Invalid spacing");return Math.round(spacing/4)*4;}

```
