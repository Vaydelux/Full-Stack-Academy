## The problem we're solving

A learner edits a feature file but commits only README, so the intended change never enters history. This lesson is an offline, repeatable source-control exercise; it never touches the learner's actual project repository or opens a hosted pull request.

## Build the mental model

A working tree contains current files, the index stages selected snapshots, and commits record staged content. Use git status to see all three states and git show to confirm a change actually entered HEAD. Clone copies repository history; this lab begins in a local initialized repository to avoid remote dependencies.

**Predict before running:** The intended lesson.txt becomes part of HEAD and the working tree has no uncommitted changes.
