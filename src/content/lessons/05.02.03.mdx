## The problem we're solving

A repository's last matching CODEOWNERS rule is ignored, requesting reviewers from the wrong team. The lesson uses synthetic local data; passing its test does not configure actual branch protection or trigger a release.

## Build the mental model

GitHub CODEOWNERS uses ordered patterns, with the last matching rule taking precedence for a file. This teaching parser supports exact names, directory-prefix patterns and /** globs only; it deliberately does not implement the entire CODEOWNERS pattern language. Real GitHub review requests need repository permissions and valid CODEOWNERS placement.

**Predict before running:** Specific later matching rules override earlier general owners in a simplified local CODEOWNERS model.

<LessonStep number={2} title="Implement the explicit review or release contract" file="labs/team-codeowners/starter/solution.mjs" expected={"Specific later matching rules override earlier general owners in a simplified local CODEOWNERS model."}>

Prefer an explicit result and a narrow, auditable policy; do not invent remote approvals or call an external API.

```js
export function solve(file,rules){if(typeof file!=='string'||!Array.isArray(rules))throw new TypeError('Path/rules required');let owner=null;for(const rule of rules){const pattern=rule.pattern;const match=pattern==='*'||(pattern.endsWith('/**')?file.startsWith(pattern.slice(0,-2)):file===pattern.replace(/^\//,''));if(match)owner=rule.owner;}return owner;}
```

**Predict before running:** Specific later matching rules override earlier general owners in a simplified local CODEOWNERS model.

**Why the repair works:** GitHub CODEOWNERS uses ordered patterns, with the last matching rule taking precedence for a file. This teaching parser supports exact names, directory-prefix patterns and /** globs only; it deliberately does not implement the entire CODEOWNERS pattern language. Real GitHub review requests need repository permissions and valid CODEOWNERS placement.

**Proof:** Run the same independent test after editing; a green result demonstrates this local policy only.

</LessonStep>
