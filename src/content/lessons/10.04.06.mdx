## The problem we're solving

The starter treats deleted operations as compatible with the previous public SDK. API schemas, operation IDs, examples, authorization descriptions and client integrations must remain consistent across changes.

## Build the mental model

Removing an operation or formerly successful response is a breaking change to generated clients; mark newly required request bodies as incompatible.

**Expected outcome:** An unchanged document has no breaking changes; removed POST or removed 201 is detected.

**Version and scope:** This module uses OpenAPI Specification **3.1.1** and one checked-in JSON contract at `examples/task-contract/task-api.openapi.json`. The smallest client generator is deliberately restricted to static, trusted GET/POST operations. This is a bounded method/status regression model; full semantic compatibility must compare schemas, required fields, enum narrowing, security and response media changes.

<LessonStep number={2} title="Build the valid OpenAPI 3.1 integration" file="labs/openapi-contract-compat/starter/solution.mjs" expected="An unchanged document has no breaking changes; removed POST or removed 201 is detected.">

```js
export function findBreakingChanges(previous,next){
 const breaks=[];
 for(const [route,verbs] of Object.entries(previous?.paths??{})){
  for(const [method,operation] of Object.entries(verbs)){
   if(!['get','post','put','patch','delete'].includes(method))continue;
   const newer=next?.paths?.[route]?.[method];
   if(!newer){breaks.push('removed '+method.toUpperCase()+' '+route);continue;}
   for(const status of Object.keys(operation.responses??{})){
    if(/^2\d\d$/.test(status)&&!newer.responses?.[status])breaks.push('removed response '+status+' '+method.toUpperCase()+' '+route);
   }
   if(operation.requestBody?.required!==true&&newer.requestBody?.required===true)breaks.push('new required body '+method.toUpperCase()+' '+route);
  }
 }
 return breaks;
}
```

**Why this corrects the contract:** Removing an operation or formerly successful response is a breaking change to generated clients; mark newly required request bodies as incompatible.

</LessonStep>
