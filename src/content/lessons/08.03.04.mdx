## The problem we're solving

The starter forces a dense 12-column grid on narrow screens. Enterprise interfaces need correct data scope, stable identities, accessible states and predictable behavior under pagination, refresh and mobile layouts.

## Build the mental model

Make mobile tables usable with deliberate cards or horizontal scrolling, while preserving important labels and data parity.

**Prediction:** At mobile widths and high column counts, choose a labeled card view; otherwise keep a semantic table.

**Scope of evidence:** The instructor's local Node tests exercise a pure data transformation. TanStack Table v8 and TanStack Virtual require separate dependency installation and mounted browser tests. Never treat sorting the current server page as global sorting, or browser-side role checks as server authorization.
