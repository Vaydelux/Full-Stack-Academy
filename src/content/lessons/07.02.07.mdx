## The problem we're solving

A private API key is stored in a NEXT_PUBLIC environment variable and imported by browser-rendered code. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

NEXT_PUBLIC-prefixed environment variables are intentionally exposed to browser bundles. Keep secrets on the server, validate authorization before accessing secret-backed services, and use the server-only import guard for modules that must never enter client bundles.

**Predict before running:** The repaired implementation respects its documented contract.
