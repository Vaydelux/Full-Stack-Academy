## The problem we're solving

An application imports undocumented files from a package's src/internal folder even though its exports map supports only the public API. This offline workshop is part of the Git/monorepo track; no workspace installation, external package query or Vercel build runs when reading the lesson.

## Build the mental model

The package.json exports map defines supported entry points for Node and bundlers that honor the map. Internal files may exist on disk without being public import specifiers. Consumers should import the package name or permitted subpaths, and releases must provide actual matching output files.

**Predict before running:** The package root and documented utils subpath resolve, but internal source paths do not.
