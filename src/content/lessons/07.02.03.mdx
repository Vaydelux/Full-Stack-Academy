## The problem we're solving

A server database row includes internal tokens, dates and ORM methods. A Client Component needs only a safe and serializable card title and identifier.

**Symptom:** The starter spreads the entire server row into client props, copying an internal token and Date instance.

## Build the mental model

Pass a minimal allowlisted React-serializable DTO across the Server-to-Client boundary; keep secrets and server-only objects server-side.

**Predict first:** Only id, title and ISO date cross the boundary; private token and Date instance are excluded.

The local fixture tests only an isolated TypeScript/React contract; actual Server Component compilation, network transport, streaming, Server Actions, security isolation and browser hydration require a separate compiled Next.js 16 application and integration tests.

```tsx
export type ServerCourse={id:string;title:string;createdAt:Date;internalToken:string};
export function toClientCourse(row:ServerCourse){
 return {id:row.id,title:row.title,createdAtIso:row.createdAt.toISOString()};
}
```

**Why it works:** Pass a minimal allowlisted React-serializable DTO across the Server-to-Client boundary; keep secrets and server-only objects server-side.

**Framework-oriented example (illustrative; needs real imports and infrastructure):**

```tsx
// Server Component or data access module
import 'server-only';
const row=await db.course.findUniqueOrThrow({where:{id:courseId}});
const publicCourse={id:row.id,title:row.title,createdAtIso:row.createdAt.toISOString()};
return <CourseCard course={publicCourse}/>;
// CourseCard.tsx
'use client';
export function CourseCard({course}:{course:{id:string;title:string;createdAtIso:string}}) {
 return <article><h2>{course.title}</h2><time dateTime={course.createdAtIso}>{course.createdAtIso}</time></article>;
}
```

**Boundary note:** React supports some richer serializable types, but an explicit DTO is a safer public API contract. Never assume a class instance, database client, closure or secret can safely cross the network.
