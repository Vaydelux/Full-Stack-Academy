## The problem we're solving

A Server Component passes an Error instance and secret-bearing object to a Client Component as though they were a safe public JSON DTO. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Server-to-client props must be serializable by the React transport and contain only public data. Convert nonserializable class instances into explicit primitives and project allowlisted fields; never serialize credentials or private attributes.

**Predict before running:** The repaired implementation respects its documented contract.
