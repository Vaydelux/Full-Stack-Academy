## The problem we're solving

A dashboard caches both public catalog summaries and personalized account data in one function. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Keep cache scopes narrow and aligned with data ownership. Cache public deterministic data in an explicit use cache boundary when Cache Components is enabled; keep session-bound data uncached or use a correctly isolated documented private strategy.

**Predict before running:** The repaired implementation respects its documented contract.
