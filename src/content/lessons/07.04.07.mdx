## The problem we're solving

A documentation site's category tree generates multiple URLs for the same lesson and lacks stable navigational breadcrumbs. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Search discoverability improves when URL structure, navigation, headings, internal links and canonical metadata agree. Choose one stable URL per document and connect related topics with accessible links; avoid doorway or duplicate-content shortcuts.

**Predict before running:** The repaired implementation respects its documented contract.
