## The problem we're solving

Documentation pages form a learning path but some links point to empty placeholders. Browsers and crawlers need a clean hierarchy of published content.

**Defect:** The starter constructs navigation from every catalog entry, including unpublished topics.

## Build the mental model

Create a clear semantic hierarchy and internal links to published content; hide placeholder pages from indexing while keeping navigation discoverable.

**Predict before running:** Only published chapters appear in the public table of contents and the original dataset is not mutated.

The academy exercises reviewed TypeScript/React logic locally. It does not automatically exercise the Next.js Metadata API, search crawler, browser page loading, network waterfall, Lighthouse or real-user field metrics. Those are separate qualification gates.
