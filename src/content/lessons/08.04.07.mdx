## The problem we're solving

A hero image lacks reserved dimensions and pushes the page's main action offscreen after loading.

## Build the mental model

Cumulative Layout Shift reflects unexpected movements in the viewport. Reserve image and embed space using dimensions or aspect ratio; trace actual shifts with browser tools instead of assuming that a single calculated value represents real field CLS.

**Predict first:** A simple shift contribution equals impact fraction times distance fraction; actual CLS needs real browser observation.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-layout-stability/starter/solution.ts" expected="A simple shift contribution equals impact fraction times distance fraction; actual CLS needs real browser observation.">

```ts

export function solve(impact:number,distance:number):number{if([impact,distance].some(x=>!Number.isFinite(x)||x<0||x>1))throw new TypeError("Invalid fractions");return impact*distance;}

```
