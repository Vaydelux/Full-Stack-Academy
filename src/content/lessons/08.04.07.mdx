## The problem we're solving

The starter reserves zero height for images, risking layout shift. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Reserve image/embed aspect ratio and display size before data arrives to avoid unexpected content movement.

**Expected outcome:** The reserved height reflects width and aspect ratio; invalid dimensions are rejected.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.
