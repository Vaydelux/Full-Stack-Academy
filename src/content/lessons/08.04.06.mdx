## The problem we're solving

The starter reports full coverage after one desktop browser test. Mature design QA tests user comprehension, accessibility, visual hierarchy and realistic layout under stress, not merely whether an interface renders.

## Build the mental model

Build a repeatable browser and input-device coverage matrix instead of assuming passing Chromium tests prove Safari and Firefox behavior.

**Expected outcome:** Complete coverage requires Chromium, Firefox and WebKit with keyboard and touch/mobile coverage.

**Evidence boundary:** This local test verifies a deterministic model or audit decision. It cannot claim a WCAG audit, human usability result, assistive technology behavior, actual CLS/LCP measurement, or cross-browser compatibility. Collect those in a real locally served application with documented scenarios.

```tsx
export type Coverage={engine:string;input:string};export function coverageComplete(items:readonly Coverage[]){const engines=new Set(items.map(x=>x.engine));const inputs=new Set(items.map(x=>x.input));return ['chromium','firefox','webkit'].every(x=>engines.has(x))&&['keyboard','touch'].every(x=>inputs.has(x));}
```

**Reasoning:** Build a repeatable browser and input-device coverage matrix instead of assuming passing Chromium tests prove Safari and Firefox behavior.

</LessonStep>

assert.equal(mod.coverageComplete([{engine:'chromium',input:'mouse'}]),false);assert.equal(mod.coverageComplete([{engine:'chromium',input:'keyboard'},{engine:'firefox',input:'keyboard'},{engine:'webkit',input:'touch'}]),true);assert.equal(mod.coverageComplete([]),false);

**Representative UI example and QA checklist:**

```tsx
// Recommended Playwright projects: chromium, firefox, webkit.
// Test 320px, 200% zoom, keyboard focus, file upload and reduced motion.
// Real mobile browsers and assistive technologies still need device checks.
// Source checks cannot prove Safari-specific rendering or touch behavior.
```

A high-quality release gate combines keyboard and touch interaction, actual screen-reader observations, image/embedding stability, and valid WCAG/heuristic assessment.

</LessonStep>
