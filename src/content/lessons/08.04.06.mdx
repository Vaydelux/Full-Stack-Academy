## The problem we're solving

A feature is enabled based solely on a user-agent substring and breaks on a browser where the expected API is missing.

## Build the mental model

Use feature detection for optional capabilities and provide progressive enhancement. Test functionality and focus semantics in multiple browser engines; user-agent sniffing is brittle and does not prove API availability.

**Predict first:** Optional enhancements are enabled only when the required capabilities are present, otherwise a stable fallback is selected.

<LessonStep number={2} title="Fix the policy and verify edge cases" file="labs/ui-cross-browser-qa/starter/solution.ts" expected="Optional enhancements are enabled only when the required capabilities are present, otherwise a stable fallback is selected.">

```ts
export function solve(capabilities:{dialog:boolean;observer:boolean}):string{return capabilities.dialog&&capabilities.observer?"enhanced":"progressive-fallback";}

```
