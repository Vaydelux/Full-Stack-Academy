## The problem we're solving

Tracking query parameters generate separate canonical URLs for the same article, fragmenting search indexing. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A canonical URL identifies the preferred public document independent of marketing parameters. Open Graph describes social previews, using an absolute image URL and accurate title. Canonical metadata cannot repair inaccessible or duplicate page content by itself.

**Predict before running:** The repaired implementation respects its documented contract.
