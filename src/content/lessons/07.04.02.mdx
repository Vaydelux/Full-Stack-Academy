## The problem we're solving

An article appears at a query-string variant and a canonical URL. Sharing and search indexing should refer to one trusted HTTPS origin.

**Defect:** The starter accepts arbitrary external URLs as canonical destinations.

## Build the mental model

Build absolute canonical/OG URLs from an allowlisted site origin and validated route parameters; never trust arbitrary user-controlled origin strings.

**Predict before running:** The known slug resolves to a single HTTPS origin; malicious or malformed IDs throw.

The academy exercises reviewed TypeScript/React logic locally. It does not automatically exercise the Next.js Metadata API, search crawler, browser page loading, network waterfall, Lighthouse or real-user field metrics. Those are separate qualification gates.

<LessonStep number={2} title="Repair the measurable contract" file="labs/next-canonical-og/starter/solution.tsx" expected="The known slug resolves to a single HTTPS origin; malicious or malformed IDs throw.">

```tsx
export function canonicalArticleUrl(origin:string,slug:string){
 const site=new URL(origin);
 if(site.protocol!=='https:'||site.username||site.password||site.pathname!=='/'||site.search||site.hash)throw new Error('Invalid origin');
 if(!/^[a-z0-9]+(?:-[a-z0-9]+)*$/.test(slug))throw new Error('Invalid slug');
 return new URL('/articles/'+slug,site).toString();
}
```

**Root principle:** Build absolute canonical/OG URLs from an allowlisted site origin and validated route parameters; never trust arbitrary user-controlled origin strings.

</LessonStep>

<LessonStep number={3} title="Verify an edge case and examine framework usage" file="labs/next-canonical-og/solution.test.mjs" expected="A valid and an invalid input satisfy the instructor's local assertions.">

```js
assert.throws(()=>mod.canonicalArticleUrl('http://academy.example','x'),/Invalid origin/);

```

**Next.js 16 usage pattern (illustrative):**

```tsx
// metadata export on a public article page
export const metadata={
 metadataBase:new URL('https://academy.example'),
 alternates:{canonical:'/articles/react-tips'},
 openGraph:{title:'React tips',url:'/articles/react-tips',type:'article',images:['/og/react-tips.png']}
};
```

**Production nuance:** Canonicals cannot solve duplicate private content. Do not generate public OG images or metadata for access-controlled records. Verify the actual canonical and crawler response in the locally built app.

</LessonStep>
