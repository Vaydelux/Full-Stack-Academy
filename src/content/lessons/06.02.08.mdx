## The problem we're solving

A batch action should add two points without repeatedly using a stale captured count. A handler that enqueues the same captured snapshot twice loses an update. The following exercise is React 19 and TypeScript 5 source checked into this repository, not a remote code runner.

## Build the mental model

Queue updater functions when an event needs multiple state transitions; each updater receives current queued state. Provide functional updaters that take the most recent queued state. **Important boundary:** A pure-function test validates state transitions and static React rendering checks initial markup; neither alone simulates an interactive browser or verifies hydration and effect behavior.

**Predict before you run:** Starting at five and applying both queued updaters results in seven, not six or one.

**Root cause:** The starter violates the rule established in the mental model. Use a small input and read the actual prior state before changing code.

**Repair:** Queue updater functions when an event needs multiple state transitions; each updater receives current queued state.
