## The problem we're solving

A delayed update captures an old count, so another click during the delay can be overwritten by the late callback. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Closures capture the variables from the render in which they were created. A functional setter reads the latest queued state at application time and avoids overwriting newer changes with a stale snapshot.

**Predict before running:** The repaired implementation respects its documented contract.
