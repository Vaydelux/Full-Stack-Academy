## The problem we're solving

A typed patch helper accepts partial updates but returns the unmodified object, so the requested change is never applied. This advanced-types lab requires both compile-time evidence and meaningful runtime behavior; TypeScript's erased types alone cannot fix logic bugs.

## Build the mental model

Mapped types transform an existing type's property keys. A readonly optional patch can preserve key/value correspondence, while spreading target and patch returns a new shallow object. For nested objects, copy each modified layer separately.

**Predict before running:** The patch changes only permitted fields while preserving the previous object's values.

```ts
export type Patch<T>={readonly [K in keyof T]?:T[K]};export function solve<T extends object>(target:T,patch:Patch<T>):T{return {...target,...patch};}
```
