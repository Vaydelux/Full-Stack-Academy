## The problem we're solving

Two text fields keep disconnected local copies, so their preview panels disagree about the same value. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

When sibling components need the same source of truth, move the state to their nearest shared owner and pass values and callbacks down through props. Do not synchronize two independent copies using cascading Effects.

**Predict before running:** The repaired implementation respects its documented contract.
