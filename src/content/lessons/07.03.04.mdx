## The problem we're solving

A mutation always purges the entire site cache instead of invalidating only the affected course data. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

Choose invalidation to match consistency needs: updateTag in Server Actions for read-your-own-writes, revalidateTag with profile max for stale-while-revalidate, and revalidatePath when a route path is the right unit. Perform an authorized successful write before invalidating.

**Predict before running:** The repaired implementation respects its documented contract.
