## The problem we're solving

A route handler forwards arbitrary user-supplied URLs to a server fetch, opening an SSRF risk. This local fixture isolates a concrete failure before we introduce any external state or deployment.

## Build the mental model

A Backend-for-Frontend Route Handler should validate user input, use an allowlisted upstream and return narrow status/data contracts. It is not a general-purpose open proxy. Keep authenticated data uncached unless a documented, correctly partitioned policy exists.

**Predict before running:** The repaired implementation respects its documented contract.
