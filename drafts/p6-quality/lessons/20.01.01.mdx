# Images containers and layers

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A mutable image tag differs across machines.

## Step 1 — Mental model

Images have immutable digest identity; containers are runtime instances with writable state.

## Step 2 — Guided practice

Compare a synthetic digest and tag-only input to containerPolicy; inspect a real Docker image digest separately.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Digest form meets the pinning policy.

**Negative:** A mutable tag alone fails the model.
