> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A dependency update introduces a critical advisory.

## Step 1 — Mental model

Scan genuine locks using current advisory data; exceptions need bounded review.

## Step 2 — Guided practice

Inspect audit:dependencies; reason about a synthetic critical result and expired exception.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Only reviewed permitted results pass.

**Negative:** Critical, expired or unavailable advisory evidence blocks qualification.
