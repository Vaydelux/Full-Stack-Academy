# Service unit tests

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A task service returns a minimal owner DTO.

## Step 1 — Mental model

Assert authorization and public data shape rather than private persistence fields.

## Step 2 — Guided practice

Call scopedRead for the owner and add a private field to the input row; assert exact response keys.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Only id and title are returned.

**Negative:** Foreign owner or private field leakage fails.

Run the complementary local module model and inspect `scopedRead` in `examples/p6-quality/labs.mjs`. Add an assertion for the relevant boundary. This command does not execute the external tools described above.

```bash
node --test --test-name-pattern="19[.]03" examples/p6-quality/labs.test.mjs
```

## Qualification boundary

Synthetic row/actor model; no Nest DI, network server, PostgreSQL or RLS execution.

## Applied engineering walkthrough

A service unit test protects domain decisions and returned data, not just internal calls. An explicit DTO projection prevents accidental leakage of newly added persistence fields. Tenant and owner authorization should be exercised independently of the successful mapping.

### Diagnose the concrete failure

Use the existing scopedRead model with an allowed actor and a row containing a synthetic private field. Assert exact public keys and values. Repeat with a foreign actor and confirm no private information is returned.

### Independent exercise and evidence

Design tests for missing record, wrong tenant and a permitted owner with extra stored fields. Record exact expected output and the policy decision; actual HTTP serialization remains a separate gate.

**Evidence boundary:** These are practice instructions, not recorded test results. Preserve the existing model, specification and draft flag; external runtime qualification remains independent.
