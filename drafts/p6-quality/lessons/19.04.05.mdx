# Chaos injection basics

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A local dependency becomes unavailable temporarily.

## Step 1 — Mental model

Chaos needs an isolated target, bounded fault, hypothesis and recovery criterion.

## Step 2 — Guided practice

Inject a deterministic failure into a disposable handler; measure with latencyReport and restore the handler.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Error rate returns to the target after recovery.

**Negative:** Unbounded retries or zero samples fail the experiment.

Run the complementary local module model and inspect `latencyReport` in `examples/p6-quality/labs.mjs`. Add an assertion for the relevant boundary. This command does not execute the external tools described above.

## Qualification boundary

Metrics model uses supplied samples; no real load generation, chaos or database benchmark.

## Applied engineering walkthrough

Fault injection is a controlled experiment with a hypothesis, bounded blast radius and recovery condition. A local dependency stub can reproduce a temporary failure without affecting real customers. Retry budgets and backpressure should prevent amplification.

### Diagnose the concrete failure

Configure a disposable handler to reject a known sequence of requests and then recover. Collect failure counts and latency before, during and after the fault. Verify that retries are bounded and that recovery restores the intended behavior.

### Independent exercise and evidence

Write a fault experiment record with scope, stop condition, expected degradation and recovery evidence. Include the no-samples case, which must not be interpreted as successful availability.

**Evidence boundary:** These are practice instructions, not recorded test results. Preserve the existing model, specification and draft flag; external runtime qualification remains independent.
