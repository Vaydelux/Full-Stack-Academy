# Image security

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A pinned base image has vulnerable packages.

## Step 1 — Mental model

Pinning is reproducibility, not scanning. Review SBOM, advisory findings and provenance.

## Step 2 — Guided practice

Run the pinning check; scan an actual local image separately and document digest and dispositions.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Real findings have explicit review and blocking policy.

**Negative:** Scanner outage or unknown digest cannot count as clean.

Run the complementary local module model and inspect `containerPolicy` in `examples/p6-quality/labs.mjs`. Add an assertion for the relevant boundary. This command does not execute the external tools described above.

## Qualification boundary

Declarative policy model; no Docker engine, image build, scan or real network isolation executed.

## Knowledge check

1. Which public behavior or invariant is being protected?
2. Which negative case falsifies the unsafe implementation?
3. Which real runtime or manual check is still required?
