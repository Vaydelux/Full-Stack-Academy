# Secret handling

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A build log accidentally exposes a credential.

## Step 1 — Mental model

Secrets require least-privilege access and isolation from untrusted code; masking alone is insufficient.

## Step 2 — Guided practice

Design a fake secret and sanitized log fixture; review hypothetical PR job permissions without enabling Actions.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Fake marker never reaches output.

**Negative:** Giving untrusted code a deployment secret fails.

Run the complementary local module model and inspect `matrixGate` in `examples/p6-quality/labs.mjs`. Add an assertion for the relevant boundary. This command does not execute the external tools described above.

Synthetic CI evidence only; no hosted workflow, branch protection change or cryptographic provenance.
