# Linux filesystem and permissions

> Unpublished instructor manuscript. A green model test is not real runtime acceptance.

## Learning outcomes

Explain the design rule, reproduce or specify an observable positive and negative experiment, and distinguish the model from external evidence.

## Context

A Linux service stores a secret and writable data.

## Step 1 — Mental model

Ownership and permissions grant only necessary access; avoid broad chmod fixes.

## Step 2 — Guided practice

In a disposable directory create a fake secret; compare owner-only with world-readable permissions.

Predict the outcome before running the experiment. Use only synthetic data and disposable fixtures.

## Step 3 — Acceptance

**Positive:** Only intended local account reads the file.

**Negative:** World-readable secret fails.
