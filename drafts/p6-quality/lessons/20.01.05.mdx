## Applied engineering walkthrough

Container networks limit reachability according to actual topology. Publishing a port maps access to the host and can expose services beyond the intended application network. Internal service discovery and database authentication are separate controls. A private network alone is not authorization.

### Diagnose the concrete failure

Inspect a disposable Compose configuration and verify only the intended ingress is published. Confirm the app reaches its database by service name, while the database has no direct public mapping. Test connectivity only within the authorized test topology.

### Independent exercise and evidence

Draw the network segments and allowed flows for edge, app, worker and database. Record inspected port bindings and connectivity outcomes, and keep credential and role tests independent.
