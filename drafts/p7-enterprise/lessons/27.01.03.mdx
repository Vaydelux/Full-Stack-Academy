# Information architecture

> Instructor draft. Local models do not qualify external identity, billing, privacy compliance or an actual capstone release.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A user needs to find tasks and account settings.

## Step 1 — Mental model

Information architecture maps pages, navigation, hierarchy, auth boundaries and empty/error states.

## Step 2 — Guided practice

Create route inventory and task-flow diagram for public and protected pages.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Core tasks can be completed with predictable navigation.

**Negative:** Protected page linked without authorization or dead-end error fails.

Inspect the complementary `webAcceptance` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

## Applied engineering walkthrough

Information architecture connects user goals to route ownership, navigation and authorization. Distinguish public documentation, sign-in, organization selection and protected workspace screens. A route diagram must include loading, empty, denied and failure states, not just the successful dashboard.

### Diagnose the concrete failure

Trace a signed-out visitor opening a protected task link, a member switching organizations and a missing task. Identify when the server authorizes the destination and when the UI can safely display data.

### Independent exercise and evidence

Create a route inventory with page purpose, required identity, data dependencies and expected error behavior. Test direct navigation and refresh as well as sidebar navigation; avoid duplicate navigation trees that can drift.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status and verify actual application, browser and human review evidence independently.
