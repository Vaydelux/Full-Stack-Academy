# Search

> Instructor draft. Local models do not qualify external identity, billing, privacy compliance or an actual capstone release.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A user searches many task descriptions.

## Step 1 — Mental model

Search applies tenant/ACL filters before ranking and returns bounded results; index updates need freshness contract.

## Step 2 — Guided practice

Seed disposable search with similar terms in two tenants; test query, pagination and stale update.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Relevant own records returned only.

**Negative:** Foreign result or unbounded search fails.

## Applied engineering walkthrough

Search results are a derived index with explicit freshness and access contracts. Filter by authorized tenant and relevant ACL before ranking, bound query and page size, and use stable result ordering. A delayed indexing event must not overwrite a newer document version or resurrect a deleted item.

### Diagnose the concrete failure

Seed similar synthetic task titles in two tenants and query as one member. Test pagination, an oversized query and an older index update arriving after deletion. Verify the foreign record never appears in results or counts.

### Independent exercise and evidence

Document index fields, source version, rebuild strategy and expected freshness. Record result IDs, denied requests and stale-event decisions; distinguish a local ranking example from actual engine and database qualification.
