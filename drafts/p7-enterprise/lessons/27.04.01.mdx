# Docker compose and envs

> Instructor draft. Local models do not qualify external identity, billing, privacy compliance or an actual capstone release.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A local app needs a reproducible multi-service environment.

## Step 1 — Mental model

Compose declares service dependencies, private networking, volumes, env boundaries and health checks.

## Step 2 — Guided practice

Create a disposable stack with app and DB; use synthetic secrets and inspect port exposure and readiness.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Stack starts reproducibly and DB is private.

**Negative:** Public DB or credentials in committed env fails.

## Applied engineering walkthrough

Compose describes a local multi-service topology, not a production security boundary by itself. Give the API and database a private network, persist the intended database volume and publish only ports required by the exercise. Keep secrets outside image layers and distinguish process startup from application readiness.

### Diagnose the concrete failure

Start a disposable application and database stack with synthetic configuration. Inspect published ports, service discovery and health checks. Delay database readiness and verify the application handles the dependency without losing data or exposing the database publicly.

### Independent exercise and evidence

Record image identities, environment sources, volumes and readiness results. Restart the stack and verify committed data survives; test teardown without deleting unrelated volumes. Do not treat a Compose file inspection as actual container execution.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status and independently verify actual infrastructure, build, security, performance, recovery and reviewer evidence.
