# Authenticated workspace

> Instructor draft. Local models do not qualify external identity, billing, privacy compliance or an actual capstone release.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A signed-in user opens a workspace.

## Step 1 — Mental model

Server verifies identity and membership; client routes reflect authorization but are not the boundary.

## Step 2 — Guided practice

Implement local session fixture and authorized/anonymous/foreign workspace navigation tests.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Authorized actor sees own workspace.

**Negative:** Foreign data or protected route relying only on UI guard fails.

Inspect the complementary `webAcceptance` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

## Applied engineering walkthrough

Authentication establishes identity, while authorization determines whether that identity may perform a particular action in the selected organization. A frontend route guard can improve navigation but cannot protect the underlying data. Resolve the actor and active membership at the server for every protected operation.

### Diagnose the concrete failure

Use synthetic signed-in, anonymous and foreign-tenant sessions to open the same workspace route and call its data endpoint directly. Remove membership after navigation and verify the next protected request is denied.

### Independent exercise and evidence

Define session expiry, sign-in return path and safe denied states. Record actual response status and absence of foreign data, including cached content during account switching. Never pass client-supplied tenant context as proof of membership.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status and verify actual application, browser and human review evidence independently.
