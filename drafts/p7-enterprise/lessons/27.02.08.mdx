## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A learner defends secured API milestone.

## Step 1 — Mental model

Review contracts, migrations, auth verification, isolation, tests and recorded exact commit before accepting.

## Step 2 — Guided practice

Run apiAcceptance; gather actual request traces and DB role tests for all required cases.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Evidence establishes documented authorization and DTO policy.

**Negative:** Missing negative test, secret exposure or wrong commit blocks review.

Inspect the complementary `apiAcceptance` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.
