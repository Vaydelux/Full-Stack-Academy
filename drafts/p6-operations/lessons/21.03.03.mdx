# Log retention and privacy

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

Logs persist user data longer than necessary.

## Step 1 — Mental model

Retention follows legitimate purpose, access control and deletion policy; avoid logging unnecessary personal data.

## Step 2 — Guided practice

Create synthetic log files with two retention classes, define expiry and verify a dry-run deletion list.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Only expired eligible records are selected.

**Negative:** Private payloads or unbounded retention fail policy.

## Qualification boundary

Synthetic incident decisions only; no real emergency response, restored backups, alerting or production capacity measurements.

## Applied engineering walkthrough

Log retention should reflect purpose, data sensitivity and applicable obligations. Diagnostic logs need not retain complete request bodies. A deletion process should respect documented holds and select only eligible expired objects. Backup retention is a separate lifecycle.

### Diagnose the concrete failure

Create two classes of synthetic log files and use an explicit clock to produce a dry-run expiry list. Verify active and held records remain excluded. Inspect a fake sensitive marker and ensure it is not collected in the intended logger output.

### Independent exercise and evidence

Design access, retention and deletion controls with a documented approval for exceptions. Record eligible identifiers and dry-run results without touching real records.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve the existing specification, model and unpublished status. Actual incident and recovery qualification remain independent.
