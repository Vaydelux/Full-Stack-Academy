# Sagas and orchestration

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

Checkout coordinates payment and shipment across services.

## Step 1 — Mental model

A saga sequences local transactions and compensations; compensation is a business action, not distributed rollback.

## Step 2 — Guided practice

Design reserve, charge, ship steps and payment failure compensation; record idempotency keys.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Failed charge releases reservation via a retriable compensation.

**Negative:** Compensation failure without recovery state or double charge fails.

Inspect the complementary `idempotentConsumer` model in `examples/p6-operations/labs.mjs` and extend its assertions where relevant. The command below does not execute the external tools discussed in this topic.

```bash
node --test --test-name-pattern="23[.]03" examples/p6-operations/labs.test.mjs
```

## Qualification boundary

In-memory synthetic idempotency model; no broker, durable store, transactional outbox or exactly-once side-effect evidence.

## Applied engineering walkthrough

A saga coordinates local transactions across independent services. Compensation is a new business operation that attempts to repair an earlier effect; it is not a distributed rollback. Compensation can fail, and external writes need stable identities and explicit uncertainty handling.

### Diagnose the concrete failure

Sketch reserve, charge and ship steps, then simulate a definitive payment failure before shipment. Verify the intended compensation releases the reservation. Model a failed compensation and ensure the workflow remains recoverable rather than reporting success.

### Independent exercise and evidence

Design a persisted saga state machine with idempotent steps, compensation retries and escalation. Record each transition and external effect identity; actual provider behavior requires independent qualification.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve the existing specification, model and unpublished status. Actual persistence, broker and provider qualification remain independent.
