# Font and image optimization

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

A hero image and web font delay meaningful content.

## Step 1 — Mental model

Choose responsive image sizes, reserved dimensions, suitable formats and limited critical font loading.

## Step 2 — Guided practice

Measure a disposable page before/after responsive assets and explicit dimensions under fixed browser settings.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Lower transfer and stable layout with acceptable visual quality.

**Negative:** Preloading every asset or dimensionless image regressions fail.

Inspect the complementary `webBudget` model in `examples/p6-operations/labs.mjs` and extend its assertions where relevant. The command below does not execute the external tools discussed in this topic.

```bash
node --test --test-name-pattern="22[.]01" examples/p6-operations/labs.test.mjs
```

Synthetic measured-value budget only; actual Core Web Vitals, browser profiles and real-user metrics are unexecuted.
