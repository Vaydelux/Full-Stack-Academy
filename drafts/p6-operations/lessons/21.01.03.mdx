# Metrics counters gauges histograms

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

An operator needs counts, queue depth and latency distributions.

## Step 1 — Mental model

Counters accumulate events, gauges report current state, histograms group observations into buckets; units and labels must be stable.

## Step 2 — Guided practice

Design request_total, queue_depth and request_duration_seconds metrics; record three requests and a queue drain.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Counter grows, gauge falls, histogram observes three durations.

**Negative:** A request ID as metric label or a decrementing request counter fails.

Inspect the complementary `safeLog` model in `examples/p6-operations/labs.mjs` and extend its assertions where relevant. The command below does not execute the external tools discussed in this topic.
