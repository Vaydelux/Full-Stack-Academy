# Domain modules and ownership

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

Orders and inventory share one application but different data rules.

## Step 1 — Mental model

Domain modules own behavior and persistence boundaries; a monolith can have independent internal contracts.

## Step 2 — Guided practice

Draw order/inventory ownership and explicit allowed dependencies; remove direct cross-module writes.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Each module controls its own data mutations.

**Negative:** A module editing another module's private table without contract fails.

## Qualification boundary

Small synthetic dependency graph only; real module enforcement, transactions and feature flag runtime not executed.

## Applied engineering walkthrough

A modular monolith can share one deployable process and database while keeping business ownership explicit. Orders should not mutate inventory's private tables through arbitrary SQL. Use a module contract to express the desired operation and let the owning module enforce its invariants.

### Diagnose the concrete failure

Draw order and inventory ownership and list current dependency edges. Propose a reservation operation through the inventory module rather than direct table writes. Test a valid reservation and an excessive quantity through that contract.

### Independent exercise and evidence

Design module ownership rules for tables, public interfaces and cross-module transactions. Record the dependency graph and actual invariant tests separately.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve the existing specification, model and unpublished status. Actual module, persistence and runtime qualification remain independent.
