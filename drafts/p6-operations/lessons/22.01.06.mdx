# Rendering waterfall analysis

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

A page waits for sequential dependent requests.

## Step 1 — Mental model

Waterfall analysis identifies dependency chains, connection delays and render-blocking resources.

## Step 2 — Guided practice

In DevTools inspect a local page with sequential requests; parallelize independent requests and compare traces.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Critical path shortens while dependent data ordering stays valid.

**Negative:** Parallelizing dependent or unauthorized requests fails.

## Qualification boundary

Synthetic measured-value budget only; actual Core Web Vitals, browser profiles and real-user metrics are unexecuted.

## Applied engineering walkthrough

A waterfall reveals when requests start and what they wait for. Independent operations can overlap, but dependent data requires correct ordering. Parallel execution also increases instantaneous pressure on shared resources. Inspect the critical path rather than assuming all parallelism is beneficial.

### Diagnose the concrete failure

Use synthetic delays for two independent requests and one dependent request. Compare sequential and parallel traces in a disposable page, retaining the necessary dependency. Verify exact returned data and authorization after the change.

### Independent exercise and evidence

Draw the request dependency graph and mark critical resources. Record start, completion and visible rendering time for matched trials, including any increased resource pressure.

**Evidence boundary:** These are practice instructions, not recorded benchmark results. Preserve the existing specification, model and unpublished status. Actual browser measurement and qualification remain independent.
