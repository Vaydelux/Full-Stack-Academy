# Backups and restore drills

> Unpublished instructor manuscript. Local model tests are supplemental, not external runtime qualification.

## Learning outcomes

Explain the relevant engineering tradeoff, define a measurable experiment and recognize the boundary of the available evidence.

## Context

A database backup job reports success every night.

## Step 1 — Mental model

A backup is not recoverability evidence until restored and validated with integrity and application checks.

## Step 2 — Guided practice

On a disposable DB restore synthetic backup into a different database, check counts and application behavior.

Use synthetic data and a disposable authorized environment. Record the expected result before the experiment.

## Step 3 — Acceptance

**Positive:** Restore works and measured duration is recorded.

**Negative:** Corrupted backup or missing restore test is not recovery proof.

## Qualification boundary

Synthetic incident decisions only; no real emergency response, restored backups, alerting or production capacity measurements.

## Applied engineering walkthrough

A backup success message proves a backup operation reported success, not that recovery works. A restore drill needs a separate authorized target and verification of schema, records, permissions and a representative application operation. Measure elapsed recovery time from a defined starting point.

### Diagnose the concrete failure

Restore a synthetic backup into a dedicated disposable database when available. Compare known row counts, constraints and an application query. Test an incomplete backup in isolation and record the failure without changing the source database.

### Independent exercise and evidence

Design a recovery checklist with backup identity, target, approval, consistency checks and cleanup. Record actual restore duration only when the drill runs.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve the existing specification, model and unpublished status. Actual incident and recovery qualification remain independent.

## Knowledge check

1. Which invariant or operational measurement determines success?
