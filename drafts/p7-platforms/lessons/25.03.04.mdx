# Map clients

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A map client loads visible results.

## Step 1 — Mental model

Client should query bounded viewport, cluster or paginate results, and preserve accessible non-map alternatives.

## Step 2 — Guided practice

Use a synthetic point list and viewport filter in a local map client; test narrow screen and keyboard alternative.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Visible bounded points and accessible list agree.

**Negative:** Fetching all private coordinates or inaccessible map-only UI fails.

Inspect the complementary `validPoint` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.
