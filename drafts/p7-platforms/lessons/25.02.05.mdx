## Context

A large handbook must be retrieved in useful sections.

## Step 1 — Mental model

Chunking trades context coherence against search granularity; preserve source and offsets and measure retrieval recall.

## Step 2 — Guided practice

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Applied engineering walkthrough

Chunk size determines the balance between local detail, surrounding context and retrieval cost. Preserve source identifiers, version and offsets so retrieved fragments can be traced back to the original document. Overlap can improve context but also creates duplicates and increases token usage.

### Diagnose the concrete failure

Split a synthetic handbook at headings and compare fixed-length chunks against section-aware chunks using questions that cross boundaries. Inspect whether the correct source fragment appears among the retrieved results.

### Independent exercise and evidence

Create a small labeled corpus with expected source passages and measure recall at a fixed retrieval depth. Record chunking settings, duplicate handling and the cases that require neighboring context.
