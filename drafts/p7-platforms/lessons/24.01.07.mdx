# Secure token storage

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

An application stores an authentication token.

## Step 1 — Mental model

Keep sensitive credentials in platform-backed secure storage; protect refresh, logout and expiry behavior.

## Step 2 — Guided practice

Use synthetic tokens in a device secure-storage plugin; test logout and reinstall behavior with documented platform limits.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Token is inaccessible to unrelated app code and logout clears intended state.

**Negative:** Plain-text localStorage or logs holding a refresh token fails.
