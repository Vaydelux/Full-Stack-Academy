# Secure token storage

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

An application stores an authentication token.

## Step 1 — Mental model

Keep sensitive credentials in platform-backed secure storage; protect refresh, logout and expiry behavior.

## Step 2 — Guided practice

Use synthetic tokens in a device secure-storage plugin; test logout and reinstall behavior with documented platform limits.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Token is inaccessible to unrelated app code and logout clears intended state.

**Negative:** Plain-text localStorage or logs holding a refresh token fails.

## Qualification boundary

Native builds, WebView isolation and plugin permissions require a real device.

## Applied engineering walkthrough

Platform-backed secure storage reduces exposure of persistent credentials but does not make a compromised application or device trustworthy. Store only the credentials required for the session, keep access tokens short-lived where the authentication design permits, and define refresh, revocation and local logout separately. Do not use real credentials in practice logs or screenshots.

### Diagnose the concrete failure

Use a synthetic refresh token to trace where it is written, read and removed. Inspect ordinary preferences, web storage and logs for accidental copies. Test expiry and logout, including failure to contact the remote service; local removal does not itself demonstrate server revocation.

### Independent exercise and evidence

Document platform storage options and the actual plugin behavior on an authorized device, including backup and reinstall limitations. Submit sanitized evidence for logout, expired sessions and inaccessible storage without exposing token values.
