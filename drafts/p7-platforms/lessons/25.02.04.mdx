## Applied engineering walkthrough

An embedding index is tied to an embedding model, version, vector dimension and distance metric. Mixing incompatible embeddings may yield meaningless similarity or fail at insertion. Store source identity, version and tenant scope alongside vectors, and choose a migration strategy before changing embedding models.

### Diagnose the concrete failure

In a disposable pgvector database insert a small set of synthetic vectors, query using the selected metric and enforce tenant filtering. Attempt insertion with the wrong dimension and test a similar foreign-tenant vector.
