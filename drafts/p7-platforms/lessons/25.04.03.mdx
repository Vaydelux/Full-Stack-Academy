# FFmpeg pipeline isolation

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

An uploaded file triggers a thumbnail job.

## Step 1 — Mental model

FFmpeg processing untrusted inputs needs isolation, resource limits, timeouts and safe argument passing.

## Step 2 — Guided practice

Run mediaAllowed with exceeded pixel limit; then test a sandboxed worker on synthetic media.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Oversized input rejected before work; valid sample produces bounded output.

**Negative:** Arbitrary shell arguments or unbounded decoding fails.

Inspect the complementary `mediaAllowed` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

## Qualification boundary

Synthetic resource-bound model; no actual FFmpeg sandbox, CDN, HLS, WebRTC or moderation service acceptance.

## Applied engineering walkthrough

An untrusted media file reaches a complex decoder, so validate declared limits and isolate processing with constrained CPU, memory, disk and execution time. File extensions and metadata alone do not establish safety. Pass arguments as structured process parameters and never concatenate user input into a shell command.

### Diagnose the concrete failure

Run mediaAllowed against a fixture exceeding the pixel limit, then process a small synthetic file using a disposable constrained worker. Exercise a corrupt input and a time limit without exposing host files.

### Independent exercise and evidence

Define input and output bounds, cleanup and terminal failure behavior. Record exit status, resource observations and absence of promoted outputs after failure; distinguish model validation from actual decoder isolation.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status and independently verify actual media tools, storage, playback, provider and reviewer evidence.
