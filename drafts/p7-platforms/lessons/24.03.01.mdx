# Tauri architecture and commands

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A desktop UI needs to read one local file.

## Step 1 — Mental model

Tauri separates webview UI from Rust/native commands; treat each invocation as a privileged API.

## Step 2 — Guided practice

Map read-document command from UI to Rust validation and returned DTO.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Only documented command and scoped data cross the boundary.

**Negative:** Arbitrary shell or path access from webview fails.

Inspect the complementary `desktopAllowed` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

node --test --test-name-pattern="24[.]03" examples/p7-platforms/labs.test.mjs

## Qualification boundary

Synthetic command permission model; actual Rust commands, capability enforcement, installers and signatures require platform builds.

## Applied engineering walkthrough

The Tauri webview is a presentation boundary; native commands can reach resources beyond browser privileges. Expose narrow business operations with typed inputs and outputs, not a general filesystem or shell interface. Command identity alone does not prove caller authorization.

### Diagnose the concrete failure

Trace a synthetic document read through invocation, capability checks, native validation and response serialization. Attempt an unknown command and a valid command from an unauthorized window.

### Independent exercise and evidence

Create a command inventory with caller, arguments, privilege and failure response. Compare actual capability configuration to desktopAllowed and distinguish installed runtime evidence from model results.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status and independently verify actual Tauri builds, OS behavior and reviewer evidence.
