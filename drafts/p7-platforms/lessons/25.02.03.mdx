# Prompt injection defenses

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A retrieved document instructs the model to reveal another tenant's records.

## Step 1 — Mental model

Retrieved text is untrusted data, not authority; enforce retrieval ACLs and tool authorization outside the model.

## Step 2 — Guided practice

Insert synthetic malicious instructions in a document; reject foreign citations with citedAnswer and verify tool denial separately.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** Foreign data and unauthorized tool calls are denied.

**Negative:** Prompt instructions overriding access policy fails.

Inspect the complementary `citedAnswer` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

## Qualification boundary

Synthetic citation membership check; not evidence of factual grounding, model safety, embeddings or real provider behavior.

## Applied engineering walkthrough

Retrieved documents are untrusted content, even when they come from an authorized index. Instructions embedded in those documents must not override application policy. Enforce tenant and document access before retrieval and independently authorize every proposed tool action at execution.

### Diagnose the concrete failure

Insert a synthetic document asking the model to disclose a foreign record. Verify retrieval excludes unauthorized records, citation validation rejects unknown IDs and a separately guarded mock tool denies the proposed action.

### Independent exercise and evidence

Build a test matrix covering malicious retrieved text, invented citations and a valid citation attached to an unsupported claim. Document which checks are deterministic and which need human semantic evaluation.

**Evidence boundary:** These are practice instructions, not recorded results. Preserve draft status; independently verify actual model, database, retrieval, provider and reviewer evidence.
