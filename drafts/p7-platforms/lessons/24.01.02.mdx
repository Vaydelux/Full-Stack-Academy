# Vite React mobile entrypoint

> Instructor draft. Local models do not qualify native platforms, real providers or production deployments.

## Learning outcomes

Explain the engineering decision, reproduce or design the positive and negative experiment, and identify the remaining evidence.

## Context

A Vite SPA must load inside a mobile shell.

## Step 1 — Mental model

A mobile entrypoint bundles static assets; native webDir must match build output and remote API origins must be explicitly configured.

## Step 2 — Guided practice

Build a disposable Vite app, inspect output, configure the native shell and test offline startup.

Use synthetic data, a disposable environment and authorized accounts only. Record expected behavior before execution.

## Step 3 — Acceptance

**Positive:** The bundled UI opens without a development server.

**Negative:** A production build depending on localhost or exposing secrets fails.

Inspect the complementary `bridgeAllowed` teaching model. Extend its assertions when relevant; it is not an implementation of the full external technology.

## Qualification boundary

Native builds, WebView isolation and plugin permissions require a real device.

## Applied engineering walkthrough

A Vite production build emits static files; the native shell must bundle the actual output rather than the development server. Inspect the configured output directory and Capacitor webDir together. Backend requests remain remote unless explicitly designed for offline use. Public client configuration may be embedded in the bundle, but server credentials must never be shipped in it.

### Diagnose the concrete failure

Build the sample, then stop its development server. Check whether the expected index file and hashed assets exist in the native asset directory after synchronization. An app that works only while localhost is reachable has not demonstrated a self-contained build.

### Independent exercise and evidence

Install a disposable debug build and start it with networking disabled. Record the app version, asset location, startup outcome and the explicit offline state for remote data. Check the bundle for synthetic secret markers.

**Evidence boundary:** These are practice instructions, not recorded results. The local model cannot qualify a native build, secure storage, permissions or real hardware. Preserve draft status until external gates pass.
