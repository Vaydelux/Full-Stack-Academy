This scenario connects directly to a real full-stack engineering concern: security, consistency, user experience and the cost of retries must be considered together.

## Misconception

This Academy lab intentionally implements CAS, not a Yjs CRDT or shared text merging.

## Applied engineering walkthrough

A compare-and-swap editor rejects stale whole-document writes; a CRDT represents operations or shared structures that can merge under its defined semantics. Yjs can synchronize compatible updates, but convergence does not provide resource authorization or guarantee the merged result satisfies business intent.

### Diagnose the concrete failure

Compare two concurrent whole-note edits in the existing version fixture. Then plan a separate real Yjs experiment using two documents, independent text inserts and updates exchanged in both orders. Assert the final shared text converges without pretending the version fixture implements Yjs.

### Independent exercise and evidence

Design a collaboration architecture with authenticated document access, persisted updates, compaction and bounded message sizes. Record exact library version and convergence evidence only after running actual Yjs.
