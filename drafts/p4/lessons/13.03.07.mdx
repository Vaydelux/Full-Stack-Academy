## Architectural challenge

**Typed repository interfaces.** A repository boundary narrows a large ORM API into domain-specific operations and makes trusted request context a required argument.

**Reproducible failure:** A general repository exports the privileged PrismaClient and lets controllers pass raw where filters, so tenant checks are easy to forget.

When a service evolves from a single-developer prototype into an API used by several organizations, an apparently valid query may introduce security gaps, schema drift, or operational load. Before looking at the corrected code, describe the invariant and the actor or environment whose behavior violates it.

<LessonStep number={2} title="Apply the narrow corrected boundary" file="drafts/p4/labs/typed-tenant-repository-contract/solution.ts" expected="The data and deployment invariant is explicitly enforced or observable.">

```ts
type TenantContext = Readonly<{ verifiedTenantId: string }>;
type TaskDTO = Readonly<{ id: number; title: string }>;
interface TaskReader {
  list(ctx: TenantContext): Promise<TaskDTO[]>;
}
function createTaskReader(db: PrismaClient): TaskReader {
  return {
    async list({ verifiedTenantId }) {
      if (!verifiedTenantId) throw new Error("Unauthorized tenant");
      return db.task.findMany({
        where: { tenantId: verifiedTenantId },
        select: { id: true, title: true }, take: 50,
        orderBy: { id: "asc" },
      });
    },
  };
}
```

**Why it is safer:** Export only allowlisted operations and public DTOs. Require trusted tenant context and enforce the query's tenant predicate inside the repository implementation.

Do not assume a successful CLI or TypeScript compile proves that the caller was authorized. Generated types protect shapes, not per-request permissions. Similarly, a DB transaction cannot roll back independent external side effects.

</LessonStep>

## Design trade-offs and real-world constraints

A repository boundary narrows a large ORM API into domain-specific operations and makes trusted request context a required argument.

Export only allowlisted operations and public DTOs. Require trusted tenant context and enforce the query's tenant predicate inside the repository implementation.

TypeScript interfaces are erased at runtime. The HTTP handler must verify identity/permission and protect actual database credentials; a caller may still forge a structural object if the boundary is misplaced.

In a multi-tenant API, input validation, role-aware database credentials, optimistic concurrency, migration review and response-shape controls must be considered together. Favor bounded queries and explicit domain operations over returning raw privileged ORM interfaces to HTTP handlers. Record the query plan or migration state instead of guessing.
