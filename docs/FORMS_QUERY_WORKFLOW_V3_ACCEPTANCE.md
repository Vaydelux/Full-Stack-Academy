## Scope completed on this branch

### HTTP and security
- Enforce exact loopback Host header, not attacker-provided Host as an authority. Reject invalid Host with 421.
- Reject cross-origin and Fetch Metadata cross-site requests before the static page and API handler. Reject absolute-form and network-path request-targets with 400.
- Maintain the loopback-only listener, strict request body boundaries, fixed static file allowlist and Content Security Policy.
- Send error responses as `application/problem+json`.
- Add task status todo/doing/done and a positive integer per-task revision.
- GET one task with an ETag. Conditional PATCH status updates require `If-Match`, returning 428 when absent and 412 when stale.
- **Concurrency fix:** Read and validate body, then check the *latest* Map entry and compare revision immediately before the synchronous write. Otherwise competing PATCH requests could both validate a stale revision before awaiting their bodies.
- Add status-filtered list paging; bind each opaque cursor to its status filter and server revision. Reject repeated/unknown query parameters. Return 409 for stale version and 400 for a cursor with the wrong filter.
- No-op PATCH leaves the task revision and list revision unchanged; actual transitions invalidate pagination.
