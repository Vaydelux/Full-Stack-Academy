# Reading-first UX

The primary job is learning, not simulating an IDE. Default to a bounded-width reader, a stable curriculum sidebar, and a single explicit Practice action. Use progressive disclosure: console and diagnostics are closed by default; notes remain in the reading context. Keep the full reference catalog, bug hunts, backup and capstone accessible. No feature deletion and no automatic lesson completion. Desktop practice shows code/output together; narrow screens switch between them. The old always-visible timeline, preview, boot animation and status bar are no longer part of reading mode.

Release checks: local/preview React sandbox render and rerun, read/practice navigation, dark/light theme, notes persistence, responsive layout and planned content labels. The course catalog is distinct from published content.
